## 1. agent 是翻譯官

> 🔊 車上的小腦 ESP32 講的是 micro-ROS 的語言，
> 要靠 agent 這位翻譯官，才能接進 Pi 5 上的 ROS 2 網路。

1. ESP32 透過 USB 序列線接到 Pi 5
2. agent 把序列資料轉成 ROS 2 訊息
3. 容器裡的節點就看得到車

## 2. 啟動 agent

> 🔊 在 Pi 5 主機上執行啟動腳本，看到連線成功的訊息就代表翻譯官上工了。

```bash title="在 Pi 5 主機"
sh ~/start_agent_rpi5.sh
```

:::warn
官方文件有些地方寫成 foxy 路徑，車上實際是 **Humble**。
:::

## 3. 進容器看節點

> 🔊 另開一個終端機進入 ROS 2 容器，列出節點，找找看車子的名字。

```bash title="在車上 Docker 容器內"
ros2 node list
```

:::info
如果看不到 `/YB_Car_Node`，先檢查 `ROS_DOMAIN_ID` 是不是 20。
:::

## 4. 收尾

> 🔊 恭喜你，第一次看到車子的節點了，下一單元我們要開始遙控它。
