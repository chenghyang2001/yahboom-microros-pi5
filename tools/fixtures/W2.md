## 1. 為什麼先學小烏龜

> 🔊 在碰真車之前，我們先用一隻畫面上的小烏龜練習。
> 小烏龜不會撞壞，也不用充電，最適合拿來認識 ROS 2 的基本觀念。

- 節點：一個會做事的小程式
- 話題：節點之間廣播訊息的頻道
- 服務：一問一答的請求
- 參數：節點的設定值

## 2. 啟動小烏龜

> 🔊 先開兩個終端機，一個跑小烏龜，一個跑鍵盤遙控。

```bash title="在電腦 WSL（Jazzy）"
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
```

:::tip
鍵盤遙控視窗要保持在**最上層**，按方向鍵才有作用。
:::

## 3. 用指令讓小烏龜轉圈

> 🔊 不用鍵盤，我們直接對話題發訊息，讓小烏龜自己轉圈圈。

```bash title="在電腦 WSL（Jazzy）"
ros2 topic pub --rate 1 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}, angular: {z: 1.8}}"
```

| 欄位 | 意思 |
| --- | --- |
| linear.x | 前進速度 |
| angular.z | 旋轉速度 |
