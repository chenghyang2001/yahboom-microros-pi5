暖身 W2

ROS 2 最小必學：節點、話題、服務、參數

⏱ 90 分鐘🚗 真車：否
🎯 學習目標
用電腦 WSL 的 turtlesim 小烏龜，親手操作 ROS 2 的節點、話題、服務、參數與 launch，並知道每個觀念在這台車上對應到什麼
✅ 完成標準
只用 ros2 node list、ros2 topic echo、ros2 topic pub 三個指令，找出小烏龜的速度話題並讓它持續轉圈

1. ROS 2 是一群小程式在聊天

🔊 旁白文字

這個單元我們要學 ROS 2 最核心的四個觀念：節點、話題、服務、參數。先講一個比喻。想像一間公司，每個員工只做一件事，有人負責看路、有人負責開車、有人負責記帳。這些員工就是節點。他們之間用公司群組聊天，每個群組有名字，想知道某件事就加入那個群組，這就是話題。有時候要私下問某人一個問題並等他回答，這是服務。每個員工桌上還有一張設定單，可以隨時改，這就是參數。我們用一隻小烏龜來練習，因為小烏龜和這台車用的是完全相同的機制。

觀念 比喻 小烏龜上的例子 這台車上的例子
節點 Node 一個只做一件事的員工 /turtlesim（畫烏龜的視窗） /YB_Car_Node（ESP32 小腦）
話題 Topic 群組聊天，一直廣播 /turtle1/cmd_vel（速度） /cmd_vel（速度）
服務 Service 私訊問問題，等回答 /spawn（多生一隻烏龜） Nav2、存地圖等進階功能裡常見
參數 Parameter 桌上的設定單 background_r（背景紅色） 避障距離 ResponseDist、校準係數

準備：每開一個新的 WSL 終端機，都要先載入 ROS 2 環境

在電腦 WSL（Jazzy）
source /opt/ros/jazzy/setup.bash
# 不想每次打，可以寫進 ~/.bashrc（只要做一次）
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
ℹ️ 補充

車上是 Humble、你的 WSL 是 Jazzy。這個單元的指令兩邊完全一樣，只有 source 的路徑不同（車上容器已經幫你設好）。

2. 節點：叫出小烏龜

🔊 旁白文字

第一步，我們叫出兩個節點。第一個終端機執行 turtlesim node，會跳出一個藍色視窗，中間有一隻烏龜。第二個終端機執行 turtle teleop key，這是鍵盤遙控器。滑鼠點一下這個終端機，按方向鍵，烏龜就會動。再開第三個終端機，輸入 ros2 node list，你會看到兩個名字，就是剛剛那兩個員工。再用 ros2 node info 看其中一個，它會列出這個節點聽哪些話題、說哪些話題，這就是節點的名片。

在電腦 WSL（Jazzy）終端機 1
ros2 run turtlesim turtlesim_node
在電腦 WSL（Jazzy）終端機 2
ros2 run turtlesim turtle_teleop_key
# 滑鼠先點這個視窗，再按方向鍵 ↑ ↓ ← →
在電腦 WSL（Jazzy）終端機 3
ros2 node list
# 預期看到：
# /teleop_turtle
# /turtlesim
ros2 node info /turtlesim

ros2 node info /turtlesim 會分成幾段：Subscribers（它聽的話題，裡面有 /turtle1/cmd_vel）、Publishers（它說的話題，例如 /turtle1/pose）、Service Servers（它提供的服務，例如 /spawn）。

ros2 run 的格式是「ros2 run 套件名 執行檔名」。

對應到這台車

小烏龜 這台車（車上 Docker 容器內）
ros2 run turtlesim turtlesim_node ESP32 開機連上 agent 後，/YB_Car_Node 自動出現
ros2 run turtlesim turtle_teleop_key ros2 run yahboomcar_ctrl yahboom_keyboard
ros2 node info /turtlesim ros2 node info /YB_Car_Node
💡 小提示

鍵盤遙控「沒反應」九成是因為滑鼠焦點不在遙控那個終端機。車上的 yahboom_keyboard 也一樣，官方文件特別提醒要先點一下終端機。

3. 話題：偷聽烏龜的對話

🔊 旁白文字

ros2 topic list 會列出所有話題，其中 turtle1 的 cmd vel 是速度指令，遙控器往這裡說，烏龜在這裡聽。用 ros2 topic echo 當旁聽者，再回去按方向鍵，就會看到速度資料一筆一筆跑出來。每個話題都有固定格式，叫訊息型別。速度用的是 Twist，分成直線速度和旋轉速度兩組。好消息是，這台車的 cmd vel 用的也是 Twist，在烏龜身上學會的，可以原封不動用在車上。

在電腦 WSL（Jazzy）終端機 3
ros2 topic list
# /parameter_events
# /rosout
# /turtle1/cmd_vel
# /turtle1/color_sensor
# /turtle1/pose

ros2 topic echo /turtle1/cmd_vel      # 回終端機 2 按方向鍵，這裡就會印出資料；Ctrl+C 結束
ros2 topic info /turtle1/cmd_vel      # 看型別、幾個發布者、幾個訂閱者
ros2 topic hz /turtle1/pose           # 看發布頻率
ros2 interface show geometry_msgs/msg/Twist

Twist 的結構：

text
Vector3 linear     ← 直線速度 x, y, z（公尺/秒）
Vector3 angular    ← 旋轉速度 x, y, z（弧度/秒）

兩輪或四輪的車只會用到兩個欄位：linear.x（前進後退） 和 angular.z（左轉右轉）。

對應到這台車

小烏龜 這台車
/turtle1/cmd_vel（Twist） /cmd_vel（Twist，同型別）
/turtle1/pose（烏龜位置） /odom_raw、/odom（車子位置）
ros2 topic echo /turtle1/pose ros2 topic echo /scan、/imu、/odom_raw

4. 自己發話題：讓烏龜轉圈（本單元過關題）

🔊 旁白文字

剛剛是旁聽，現在我們親自在群組裡說話。ros2 topic pub 可以不寫任何程式，直接對一個話題發送資料。我們讓直線速度等於二、旋轉速度等於一點八，烏龜就會一邊前進一邊左轉，畫出一個圓。加上 r 一的選項，代表每秒發一次，烏龜就會一直轉下去，按 Ctrl C 才停。注意大括號裡每個冒號後面都要有一個空格，少了空格就會報格式錯誤。這是初學者最常踩的坑。

在電腦 WSL（Jazzy）終端機 3
# 持續轉圈（每秒發一次），Ctrl+C 停止
ros2 topic pub -r 1 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}, angular: {z: 1.8}}"

# 只發一次
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}, angular: {z: 0.0}}"

過關標準：不看講義，只用 ros2 node list（找節點）→ ros2 topic list／ros2 topic echo（找出速度話題、確認格式）→ ros2 topic pub（發指令）讓烏龜持續轉圈。

對應到這台車（B5 單元會在真車上做）

在車上 Docker 容器內
# 慢慢原地左轉
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.5}}"
# 停車：一定要再發一次全零
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
⚠️ 注意

ros2 topic pub 不加選項時預設每秒重複發送，直到你按 Ctrl+C。在烏龜身上沒關係，在真車上代表車會一直跑。按 Ctrl+C 後車不一定會停，要再發一次全零速度。官方範例用線速度 0.5 m/s，室內偏快，第一次建議用 0.1 以下，並把車輪架空測試。

5. 服務：一問一答

🔊 旁白文字

話題像廣播，一直講、誰想聽就聽。服務則像打電話給櫃台：你提出一個請求，對方處理完回你一個答案，一次就結束。小烏龜提供一個叫 spawn 的服務，意思是生出一隻新烏龜。我們告訴它新烏龜的座標、角度和名字，它就會在畫面上變出第二隻，並回傳名字給我們。什麼時候用話題、什麼時候用服務？持續不斷的資料，例如速度和感測器，用話題；偶爾做一次、需要確認結果的動作，例如存地圖，用服務。

在電腦 WSL（Jazzy）終端機 3
ros2 service list                       # 列出所有服務
ros2 service type /spawn                # turtlesim/srv/Spawn
ros2 interface show turtlesim/srv/Spawn # 看請求與回應的欄位（--- 上面是請求、下面是回應）

# 在 (2, 2) 生出一隻叫 turtle2 的烏龜
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.2, name: 'turtle2'}"

# 新烏龜有自己的話題，可以單獨控制
ros2 topic pub -r 1 /turtle2/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 1.0}, angular: {z: -1.0}}"

# 清掉軌跡、刪掉烏龜
ros2 service call /clear std_srvs/srv/Empty
ros2 service call /kill turtlesim/srv/Kill "{name: 'turtle2'}"
比較 話題 Topic 服務 Service
方向 單向廣播 請求 → 回應
頻率 持續 有需要才呼叫一次
例子 /cmd_vel、/scan、/imu /spawn、存地圖、清除地圖
ℹ️ 補充

這台車上：ESP32 的 /YB_Car_Node 只用話題，沒有提供服務。服務會在進階單元出現，例如 A1 存地圖、A2 Nav2 導航內部大量使用（實際服務名稱以 ros2 service list 為準）。另外還有第三種溝通方式叫 action（動作），用在「長時間任務＋過程回報」，例如導航到某個點；小烏龜可以試 ros2 action send_goal /turtle1/rotate_absolute turtlesim/action/RotateAbsolute "{theta: 1.57}" --feedback。

6. 參數：節點的設定單

🔊 旁白文字

每個節點都可以有自己的參數，像是貼在桌上的設定單，程式執行中也能改。小烏龜的背景顏色就是三個參數：background r、background g、background b，分別是紅綠藍。用 ros2 param set 把紅色調到最大，背景就會變色；param dump 還能把設定單存成檔案。在這台車上，參數非常常用。例如光達避障程式有一個參數叫回應距離，決定障礙物多近才閃避；校準里程時，也是調整一個比例係數參數。

在電腦 WSL（Jazzy）終端機 3
ros2 param list                                   # 列出所有節點的參數
ros2 param get /turtlesim background_r            # 查目前值
ros2 param set /turtlesim background_r 255        # 背景變紅
ros2 param describe /turtlesim background_r       # 看說明與範圍
ros2 param dump /turtlesim > turtlesim.yaml       # 存成 YAML 檔
ros2 param load /turtlesim turtlesim.yaml         # 從檔案載回
💡 小提示

如果 param set 回 Set parameter successful 但背景沒變，執行一次 ros2 service call /clear std_srvs/srv/Empty 讓畫面重畫。

對應到這台車（原始碼裡宣告的參數）

節點 參數 預設值 用途
laser_Avoidance（M4 光達避障） ResponseDist 0.55 障礙物多近（公尺）就閃避
laser_Avoidance linear、angular 0.3、1.0 避障時的速度
calibrate_linear（B6 校準） odom_linear_scale_correction — 里程比例係數，用 rqt_reconfigure 圖形化調整

7. 看全貌：rqt_graph 與 launch 檔

🔊 旁白文字

節點和話題一多，腦袋很難記住誰連誰。rqt graph 會畫一張關係圖，圓框是節點、箭頭上的字是話題，一眼就看懂資料怎麼流動。另外，真的機器人一次要開好幾個節點，一個一個打 ros2 run 太累。launch 檔就像一份開工清單，一個指令就把清單上的節點全部叫起來，還能順便設定參數。你在這台車上會大量用到 ros2 launch，例如手把控制，就是一個 launch 檔同時啟動手把驅動節點和控車節點。

在電腦 WSL（Jazzy）終端機 3
ros2 run rqt_graph rqt_graph
# 畫面空白時：左上選 Nodes/Topics (all)，再按左上角的重新整理

你應該會看到：/teleop_turtle ──/turtle1/cmd_vel──▶ /turtlesim。

用 launch 一次開兩隻烏龜（先把前面的終端機都 Ctrl+C 關掉）：

在電腦 WSL（Jazzy）
ros2 launch turtlesim multisim.launch.py
# 會開出兩個烏龜視窗；找不到這個 launch 檔時，改用兩個終端機各自 ros2 run
ros2 node list

這台車的 launch 檔長什麼樣子（原始碼 yahboomcar_ctrl/launch/yahboomcar_joy_launch.py，完整內容）：

python
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    node1 = Node(
        package='yahboomcar_ctrl',
        executable='yahboom_joy',     # 控車節點：讀 /joy，發 /cmd_vel、/beep、/servo_s1、/servo_s2
    )
    node2 = Node(
            package='joy',
            executable='joy_node',    # 手把驅動節點：讀 USB 手把，發 /joy
    )
    launch_description = LaunchDescription([node1,node2])
    return launch_description

這就是 ROS 常見的「驅動節點＋應用節點」分層：joy_node 只負責把手把按鍵變成 /joy，yahboom_joy 只負責把 /joy 翻譯成車子的指令。

⚠️ 注意

官方 05-3 文件寫 ros2 launch yahboomcar_ctrl yahboom_joy_launch.py，但原始碼裡的檔名是 yahboomcar_joy_launch.py。到真車上如果出現找不到檔案，請改用原始碼的檔名，或在容器內 ls /root/yahboomcar_ws/src/yahboomcar_ctrl/launch 查看（需實車確認）。

8. ROS_DOMAIN_ID：誰看得到誰

🔊 旁白文字

最後一個觀念和這台車息息相關。同一個網路上的 ROS 2 程式，會自動互相發現，就像同一棟大樓的人都能聽到廣播。但如果教室裡有十台車，大家的廣播全混在一起就亂了。ROS DOMAIN ID 就是樓層號碼，只有同一樓層的程式才看得到彼此。我們做個小實驗：兩個終端機都設成五號，一個說、一個聽，可以收到；把其中一個改成別的號碼，就收不到了。這台車預設是二十號。

在電腦 WSL（Jazzy）終端機 A
ROS_DOMAIN_ID=5 ros2 run demo_nodes_cpp talker
在電腦 WSL（Jazzy）終端機 B
ROS_DOMAIN_ID=5 ros2 run demo_nodes_cpp listener     # 收得到 Hello World
ROS_DOMAIN_ID=7 ros2 run demo_nodes_cpp listener     # 換號碼：什麼都收不到

之後要讓電腦和車互通（A5 單元），電腦這邊要加一行：

在電腦 WSL（Jazzy）
echo "export ROS_DOMAIN_ID=20" >> ~/.bashrc
⚠️ 注意

現在先不要把 20 寫進 WSL 的 ~/.bashrc，除非你已經要連車。WSL 預設是 NAT 網路，就算號碼一樣也看不到車，需要另外設定 mirrored 網路（A5 單元說明）。
