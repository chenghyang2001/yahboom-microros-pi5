## Part 2 額外安全規則

1. 車子在地上會真的跑：任何移動速度 ≤ 0.15 m/s、轉向 ≤ 0.6 rad/s；每次動作前念出「車子要動了」並等 2 秒。
2. 開始前確認：場地 2×3 公尺內沒有障礙與線材、有人在車旁、手把在使用者手上。
3. 停車：送零速度到 `/cmd_vel`（連送 3 次）。**不要用 `ycar.py stopcar`**（會把雲台送回 0 度，可能扯掉相機線）。
4. `/servo_s2` 只能 -45～0 度。
5. 建圖、導航前先讓車靜置 5 秒（陀螺儀初始化），否則 RViz 裡車會自己轉。
6. 地圖存在容器裡，容器一關就消失：存圖後立刻 `docker cp` 到 Pi 主機 `~/maps/`。
7. 光達程式的 `Switch` 參數：`laser_Avoidance`、`laser_Tracker`、`laser_Warning` 的 `Switch=True` 是「暫停」，預設 False 一啟動就會動；先確認參數再啟動。
