第二步，讓小腦 ESP32 連上翻譯官 agent。

先說現在的狀況。第一步我們在左上角第一格啟動了翻譯官 agent，它已經打開 USB 序列線在等小腦。可是我等了兩分鐘，小腦都沒有自己連上來。原因是我們剛才把舊的 agent 關掉又重開，小腦不知道翻譯官換了一個新的，所以要讓小腦重新開機一次。

這一步要請你動手：請按一下車子擴展板上，ESP32 的 Reset 按鍵，按一下就放開。

按下去以後，你會看到兩個地方有變化。

第一個是車上 ESP32 的燈號，順序跟素材寫的一樣。一開始是快閃，大約每零點三秒閃一次，這是小腦在設定自己的狀態，大約五秒鐘。接著變成慢閃，每一秒閃一次，這是小腦在找翻譯官。最後變成每三秒快閃兩次，這就是連上了，正常狀態。

第二個是螢幕三左上角的第一格。小腦一連上，翻譯官就會印出 session established，意思是連線建立了。接著會一口氣跑出一長串 created 的訊息，這是小腦在登記它要用的話題，像是電池、光達、IMU、馬達指令這些。

按完 Reset 以後，手機上的轉接通道可能會斷掉，我會自動幫你重新接好。

我念完以後就開始盯著第一格的畫面。請你現在去按 Reset。
