螢幕三上面三個格子，各自是什麼。

螢幕三現在是一個終端機視窗，我把它切成三格：左上角是第一格，右上角是第二格，下面整條是第三格。三格同時看得到，你就能一眼看到全部的狀況。

先講一個名詞：容器。拍五的作業系統是樹莓派自己的系統，可是 ROS 2 需要另外一種系統環境。所以廠商把需要的軟體，全部裝進一個獨立的小盒子裡，這個小盒子就叫做容器，管理容器的工具叫做 Docker。開機時，拍五會打開兩個容器，一個是翻譯官，一個是 ROS 2 的工作環境。

第一個，下面的第三格，叫做主機檢查用。它不在任何容器裡面，是直接在拍五的主機上打指令，用來檢查狀態。我剛才在這裡打了 docker ps，意思是列出目前正在執行的容器。結果只有一行標題，下面是空的，代表現在一個容器都沒有在跑，就跟剛開機、什麼都還沒啟動的狀態一樣。等兩個容器都打開以後，再打一次 docker ps，就會看到兩行，一行是翻譯官，一行是 ROS 2。

第二個，左上角的第一格，執行的是 start agent rpi5 點 sh。rpi5 就是 Raspberry Pi 5，也就是樹莓派五的意思。點 sh 代表這是一個腳本，就是把要打的指令先寫在一個檔案裡，執行它就等於把裡面的指令照順序打一遍。這個腳本只有一個重點指令：用 Docker 打開翻譯官容器，也就是 micro ROS agent，並且告訴它，透過 USB 序列線，用每秒九十二萬多個位元的速度，去跟小腦 ESP32 說話。

為什麼需要翻譯官？因為小腦 ESP32 是一顆很小的晶片，它講的是精簡版的 ROS 語言，叫做 micro ROS。大腦這邊用的是完整版的 ROS 2。翻譯官就站在中間，把小腦的電池、光達、IMU 這些資料翻譯成 ROS 2 的話題，也把大腦送出去的馬達指令翻譯給小腦。沒有它，大腦和小腦就沒辦法溝通。

第三個，右上角的第二格，執行的是 ros2 humble 點 sh。Humble 是 ROS 2 的一個版本名稱。這個腳本會打開 ROS 2 的工作容器，然後停在一個可以打字的畫面，等你輸入指令。它還做了幾件準備工作：讓容器可以在樹莓派桌面上開視窗，讓容器可以用相機和手把這些裝置，也讓容器跟主機共用網路，這樣容器裡面就看得到小腦送上來的話題。打開以後，它會印出 MY DOMAIN ID 二十，意思是這台車用的頻道編號是二十，同一個頻道的程式才聽得到彼此。

這裡有一個重點：第二格這個 ROS 2 容器，本身不會讓車子動起來。它比較像是一張工作桌，讓你在上面輸入 ROS 2 的指令，例如查看話題、開地圖程式。車子真正的節點，是小腦透過翻譯官送上來的。
