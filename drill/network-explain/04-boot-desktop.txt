拍五開機時發生什麼事，以及桌面上看到什麼。

第一部分，桌面上看到什麼。

用 VNC 連進拍五以後，會看到樹莓派的桌面。最上面是工作列，從左邊數過來，是樹莓派選單、瀏覽器、檔案總管，接著有三個終端機的圖示。

第一個只有圖示，那是終端機的捷徑按鈕，不是開著的視窗。

第二個寫著 root at raspberrypi，這是 Docker 容器終端，也就是 ROS 2 的環境。畫面中間那個黑色視窗就是它，裡面會印出 MY DOMAIN ID 二十。

第三個寫著 bash，這是 agent 終端，也就是 micro ROS agent。它負責在大腦樹莓派和小腦 ESP32 之間當翻譯，這個視窗通常被擋在後面。

右上角從左到右，是藍牙、Wi-Fi、音量、麥克風，還有時間。藍牙現在連著你的耳機。

第二部分，素材說的開機流程，是怎麼做到的。

素材說，樹莓派開機大約三十秒後，會自動打開 agent 終端和 Docker 容器終端。

做法是這樣：樹莓派有一個自動啟動的資料夾，裡面放了兩個捷徑檔。桌面一載入完成，系統就會照這兩個捷徑檔，各自打開一個終端機，去執行一個腳本。

第一個捷徑檔叫 start，它執行的腳本會啟動 micro ROS agent 的容器，透過 USB 序列線跟 ESP32 溝通。

第二個捷徑檔叫 uros，它執行的腳本會啟動 ROS 2 Humble 的容器，然後停在提示字元，等你輸入指令。

至於素材裡 ESP32 燈號的部分，從一開始每三百毫秒閃一次，到每一秒慢閃，最後變成每三秒快閃兩次，這是 ESP32 自己的程式在跑。它要等 agent 起來以後才連得上，連上以後就會建立電池、光達這些話題。

第三部分，你怎麼知道它真的做了。

第一，看 VNC 桌面的工作列，有沒有 root at raspberrypi 和 bash 這兩個視窗。

第二，看小腦的燈號，有沒有變成每三秒快閃兩次。或者看 agent 終端裡，有沒有出現一長串 created 的訊息。

第三，用 ycar 點 py 的 status 指令檢查，有沒有看到 YB Car Node 這個節點，光達大約每秒十二次。

第四，用 docker ps 指令，看兩個容器是不是都顯示 Up，也就是正在執行。

第四部分，兩個要注意的地方。

第一，手把控制。素材說出廠會自動啟動手把控制，但是我在這台拍五上，沒有看到任何程式在讀手把。開機自動啟動的只有剛才說的兩個終端。手把的接收器有插著，但是開機時沒有程式在用它。你可以按手把試試看，車子會不會動，我再幫你查。

第二，不要關掉這兩個終端視窗。ROS 2 和 agent 都是在終端機裡面跑的，視窗一關，對應的容器就會停掉，車子就會失聯。
