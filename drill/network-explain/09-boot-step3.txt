第三步，打開 ROS 2 工作桌容器。

這一步會照順序做三件事。

第一件，我先把下面第三格拉高一點，然後把 ros2 humble 點 sh 這個腳本的內容印出來，讓你看看它寫了什麼。

這個腳本比剛才的翻譯官腳本長一點，重點有這幾個。

第二行是 xhost 加號，意思是允許別的程式，包括容器，在樹莓派的桌面上開視窗。以後在容器裡開相機畫面、地圖畫面，才顯示得出來。

接下來是 docker run 減 i t，打開一個新容器，並且接在終端機上，讓你可以在裡面打字。注意這裡沒有減減 r m，所以這個容器停下來以後不會自動清掉，會留一個停止的容器在電腦裡。

減減 privileged 等於 true，給容器最高權限。減減 net 等於 host，跟主機共用網路，這樣容器裡才看得到小腦送上來的話題。

減減 env 等於 DISPLAY，告訴容器要把視窗畫在哪一個螢幕上。

減 v 斜線 dev 斜線 input，把手把、鍵盤這些輸入裝置借給容器。減 v 斜線 dev 斜線 video0，把相機借給容器。

最後是 yahboomtechnology 斜線 ros humble 冒號四點一點二，這是廠商做好的 ROS 2 容器映像檔，裡面已經裝好了這台車要用的所有 ROS 2 程式。後面的斜線 bin 斜線 bash，意思是打開以後，停在一個可以打字的畫面。

第二件，我會在右上角第二格，執行 sh 波浪號斜線 ros2 humble 點 sh。執行以後，你會看到三行字。第一行是 access control disabled，這是 xhost 印出來的，意思是已經允許容器開視窗。第二行是 MY DOMAIN ID 二十，這是容器裡的設定檔印的，代表這台車的 ROS 頻道是二十號。第三行的提示字元，會從原本的 pi at raspberrypi，變成 root at raspberrypi，代表你已經進到容器裡面了。

第三件，我會在第三格再打一次 docker ps。這次應該會看到兩個容器在跑，一個是翻譯官，一個是 ROS 2 工作桌。這樣就跟拍五開機自動做完的狀態一模一樣了。

我念完以後就開始執行。
