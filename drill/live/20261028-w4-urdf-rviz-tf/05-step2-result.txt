第二步的結果出來了。

先說一個小插曲。第一次開出來的 RViz 視窗太高，放不進螢幕三，鏡頭也靠太近，雲台被切到畫面外面。所以我改了模擬套件的 RViz 設定檔，把視窗調矮、鏡頭拉遠一點，然後在第一格按 Ctrl C 停掉，再重新 launch 一次。你現在看到的是第二次開的。

請看右邊的 RViz。左半邊是 Displays 面板，列出它正在畫的東西：Grid 是地上的格線，RobotModel 是車子模型，TF 是每根骨頭的座標軸。右半邊就是 3D 畫面：黑色方形的車身，四個黃色的麥克納姆輪，車頂上黑色圓柱是光達，車頭那個灰色的小方塊就是雲台和攝影機。每個零件上還有紅綠藍三色的小箭頭，那是它自己的座標軸，紅色是前方 x，綠色是左方 y，藍色是上方 z。

這台車的樣子，全部是從第一步那份 URDF 畫出來的。RViz 自己不知道車長什麼樣，它是聽身體廣播員 robot state publisher 講的。

下面第三格的 ros2 node list，列出了四個節點。前三個跟預期一樣：joint state publisher gui、robot state publisher、rviz2。第四個名字很長，叫 transform listener 加一串亂碼，它是 RViz 內部用來收聽 TF 的小幫手，RViz 一開就會自動帶出來，不用理它。

另外，有一個有滑桿的 Joint State Publisher 視窗開在別的螢幕上，我們不用它。

下一步，第三步，是本單元的過關題：讓雲台和輪子動起來。等你說繼續。
