好，鏡頭已經朝向正前方了。我們回到排定的流程，第二步：打開限速閥和手把。這一步車子還不會動。

先看右上角第二格。我要執行 python3 cmd underscore vel underscore limiter 點 py，這就是開場講的限速閥。它啟動時會印一行設定：從 cmd vel raw 收速度，送到 cmd vel，線速度上限零點一五，角速度上限零點八，看門狗零點五秒。之後官方程式只要送出太快的速度，這一格就會印出「限速」，告訴你原本多快、被夾成多少。

接著看右下角第四格，手把。要開兩個程式。第一個是 ros2 run joy joy underscore node，它負責讀手把接收器的按鍵和搖桿。第二個是 ros2 run yahboomcar underscore ctrl yahboom underscore joy，它把搖桿換算成速度。我會帶幾個參數：速度上限設小一點，推到底大約每秒零點一公尺；另外用減 r 把雲台的兩個話題改名，因為這個程式一啟動就會把雲台轉回零度，剛才調好的鏡頭又會跑掉。改了名字，它就碰不到雲台。

程式開好以後，請你打開手把電源，看到綠燈，按一下 START 鍵，聽到嗶一聲，就代表手把連上了。這時候先不要按 R1。R1 是接管開關，等車子跑起來，覺得不對勁再按，按下去，官方光達程式就會讓出控制權、停車。

我念完以後就開始執行，然後請你打開手把、按 START。
