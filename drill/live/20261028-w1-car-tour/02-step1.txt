第一步，看第一層：大腦樹莓派五，到底是一台什麼樣的電腦。

這一步全部在下面第三格，主機格，依序打四個指令。

第一個，cat 斜線 proc 斜線 device tree 斜線 model，後面加分號 echo。proc 是 Linux 放「系統即時資訊」的特殊資料夾，裡面這個 model 檔，寫著這塊板子的型號。後面的 echo 只是補一個換行，讓提示字元不要黏在同一行。預期看到 Raspberry Pi 5 Model B。

第二個，uname 減 m，印出 CPU 的架構。預期是 a a r c h 64，也就是 64 位元的 ARM 處理器，跟手機是同一家族，跟一般筆電的 x86 不一樣。這就是為什麼車上的 Docker 映像檔，要特別做 ARM 的版本。

第三個，grep PRETTY 斜線 etc 斜線 os release，看作業系統的名字。預期是 Debian 12，代號 bookworm，也就是樹莓派官方系統的底層。記住這個名字，第二步會拿來對照。

第四個，free 減 h，看記憶體，減 h 是用人看得懂的單位。預期總共大約 7.9 G，也就是八 GB 版本，現在只用了不到一 G，代表大腦還很閒。

這四個數字合起來，就是大腦的身分證：樹莓派五、ARM 64 位元、Debian 12、八 GB 記憶體。

我念完以後就開始執行。
