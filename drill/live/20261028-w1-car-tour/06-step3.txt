第三步，看硬體接在哪裡。

先記一個原則：車上大部分的感測器和馬達，都接在小腦 ESP32 上；只有相機，直接插在大腦樹莓派上。這一步要用指令證明這件事。

一樣在下面第三格，主機格，打兩個指令。

第一個，lsusb，列出所有插在樹莓派 USB 上的裝置。除了幾個 Linux Foundation 的 root hub，那是 USB 控制器本身，不用理它，預期會看到三個真正的裝置。

第一個是 Silicon Labs CP210x UART Bridge。CP210x 是一顆 USB 轉序列的晶片，焊在 ESP32 擴展板上。也就是說，整塊小腦，在大腦眼中只是一個 USB 序列裝置。馬達、陀螺儀、蜂鳴器、雲台舵機、光達，全部藏在這一個裝置後面。

第二個是 Microdia USB 2.0 Camera，就是雲台上的相機，它直接插在樹莓派上，不經過小腦。

第三個是 DragonRise Controller，是遙控手把的無線接收器，也插在樹莓派上。

第二個指令，ls 減 l 斜線 dev 斜線 tty USB 零，空格，斜線 dev 斜線 video 零。Linux 會把每個裝置變成 dev 資料夾裡的一個檔案。tty USB 零就是剛才的 CP210x，也就是通往小腦的那條序列線，翻譯官就是打開這個檔案在跟小腦講話；video 零就是相機。預期兩個檔案都存在，開頭是小寫的 c，代表字元裝置。
