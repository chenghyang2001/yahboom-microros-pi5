第三步的結果，硬體地圖畫出來了。

下面第三格的 lsusb 列出七行。四行 Linux Foundation root hub 是 USB 控制器本身，扣掉以後，剩下三個真正的裝置，跟預期完全一樣。

Silicon Labs CP210x UART Bridge：整塊小腦 ESP32，在大腦眼中就是這一個 USB 序列裝置。

DragonRise Controller：遙控手把的接收器。

Microdia USB 2.0 Camera：雲台上的相機，直接插在樹莓派上。

接著 ls 減 l 的兩行。斜線 dev 斜線 tty USB 零，群組是 dialout，序列埠的意思，這就是翻譯官打開的那條線。斜線 dev 斜線 video 零，群組是 video，就是相機。兩行開頭都是小寫的 c，字元裝置。

把這一步整理成一句話：大腦樹莓派上只直接插了三樣東西：小腦、相機、手把接收器。馬達、陀螺儀、蜂鳴器、雲台舵機、光達，全部接在小腦上，大腦看不到它們，只看得到那條 tty USB 零。

那麼，小腦後面到底藏了哪些東西？下一步，第四步，我們到右上角第二格，請小腦自我介紹：用 ros2 node info 看它開了哪些頻道。今天第二、第三個跟講義不一樣的地方，就在那裡。等你說繼續。
