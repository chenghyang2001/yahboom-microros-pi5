第二步，用鍵盤開車。車子這一步會小幅移動。

指令在右上角第二格：ros2 run yahboomcar ctrl yahboom keyboard。啟動以後，畫面會印出一張鍵盤配置表：i 是前進，逗號是後退，j 和 l 是原地左轉和右轉，空白鍵是立刻停。

這個程式有兩個重點。第一，它要「按住」才會一直走：程式每零點一秒讀一次鍵盤，連續五次，也就是半秒沒收到方向鍵，就自動把速度歸零。所以放開按鍵，車子就會停。第二，它的起始速度是每秒零點二公尺、每秒一弧度，對我們一公尺見方的場地太快了。

所以我會這樣做。先按六下 x，每按一下線速度降百分之十，降到大約每秒零點一公尺；再按三下 c，轉彎速度降到大約每秒零點七三弧度。每按一下，畫面都會印出目前的速度，你可以看到數字變小。

然後開車：按住 i 大約一秒，前進十公分；按住逗號一秒，退回原位；按住 j 一秒，原地左轉大約四十度；按住 l 一秒，轉回來。最後按空白鍵停車，再按 Ctrl C 離開程式，它離開前會自己送一筆停車指令。

同時請看左上角第一格的監視器：按方向鍵時，會出現一筆一筆的速度，linear x 是零點一左右、或 angular z 是零點七三左右；放開以後，就會變成全部是零。

因為我是從電腦把按鍵送進那一格，等於替你按鍵盤。我念完以後就開始執行。
