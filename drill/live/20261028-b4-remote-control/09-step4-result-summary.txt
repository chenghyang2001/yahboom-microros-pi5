第四步的結果，手機 App 連線成功，車子也動了，不過很快就被我們的看門狗停下來了。

這一步我用 adb 從電腦操作手機：打開 App、填入 IP 10.169.179.1、把 ROS 版本改成 ROS2，再按連接。右上角第二格的 rosbridge 立刻印出一串 Subscribed to，代表手機已經連上，開始訂閱機器人位置、攝影機影像、光達這些話題。

接著你推了輪盤。左上角第一格的監視器記錄到 App 送出的速度：一開始是負 0.022，很慢的後退，車子動了一下；但接著出現一筆 0.73，每秒七十三公分，是我們上限的好幾倍。看門狗一看到超過每秒零點二五公尺，就立刻關掉 rosbridge、連送三次零速度，車子停了，App 也斷線了。所以你感覺到的是：動一下就停了。

這正好示範了 App 的危險：它的輪盤沒有限速保護，手指稍微滑多一點，速度就會一下子跳得很高。在一公尺見方的小場地，這種速度一秒就衝出去了。所以看門狗不是設太嚴，而是它真的擋下了一次超速。以後要在小場地用 App，最好先在車上加一個限速的程式，或者換到大一點的空地。

接著是第五步，總結。初級第四單元，遙控，三種方式我們都在實車上試過了。

第一步，確認方向盤是空的：監視 cmd vel，加上 node list。第二步，鍵盤：起始速度太快，按 x 和 c 降到每秒十公分，前進、後退、左轉、右轉，放開就停。第三步，手把：第一次上限設太低，乘上檔位只有每秒三公分，車子推不動；改成每秒零點三公尺的上限以後，實際約十公分，開得很順。同時我們把手把程式的雲台話題改名，讓它碰不到雲台。第四步，手機 App：透過 rosbridge 連上，但輪盤沒有限速，被看門狗擋了下來。

三種遙控，最後都變成同一個 cmd vel；同一時間只能有一個人握方向盤；而且每一種的速度怎麼算、上限在哪，都要先看懂，才能在小空間裡安全地開。

這次演練到此結束，謝謝收看。
