第三步，看零件裝在車子的哪裡。

真車上次是用 lsusb，看哪些硬體用 USB 接在大腦上，有 ESP32、相機、手把接收器。模擬車沒有 USB，但是它有一份車子的設計圖，叫做 URDF，裡面寫了車身、四個輪子、IMU、光達、雲台和相機，每一個零件叫做一個 link，零件和零件之間的接頭叫做 joint。ROS 2 會把每個零件的位置，用一個叫 TF 的機制廣播出去，TF 就是座標轉換。

我們在右下角第三格打三次 tf2 底線 echo。格式是 ros2 run tf2 底線 ros tf2 底線 echo，後面接兩個零件名稱，意思是：從第一個零件看過去，第二個零件在哪裡。第一次看 base 底線 link 車身到 radar 底線 Link 光達，第二次看車身到 imu 底線 Link，第三次看車身到 camera 底線 link 相機。每一次讓它印兩三秒，我再按 Ctrl C 停掉。

預期光達的 Translation，也就是位移，大約是零、零、零點零七九，代表光達裝在車身中心正上方七點九公分。IMU 在車身裡面，只比車身中心高三公分左右。

最後打 ros2 run tf2 底線 tools view 底線 frames，它會聽五秒鐘，把所有零件的關係畫成一棵樹，存成檔案，我再把這棵樹的分枝印出來。同時你可以看右邊螢幕的 RViz，車子模型上每個零件都有自己的座標軸。我念完以後就開始執行。
