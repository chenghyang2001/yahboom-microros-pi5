第一步，看大腦。真車的大腦是樹莓派五，模擬車的大腦，就是你這台電腦裡的 WSL Ubuntu。

我們會在右下角的第三格，打五個小指令。第一個是 uname 減 m，看處理器的架構。第二個是讀斜線 etc 斜線 os 減 release 這個檔案，看作業系統的版本。第三個是 nproc，看有幾個處理器核心。第四個是 free 減 h，看記憶體有多大。最後印出兩個環境變數，ROS 底線 DISTRO 是 ROS 2 的版本名稱，ROS 底線 DOMAIN 底線 ID 是這台機器的頻道號碼。

預期會看到：架構是 x86 底線 64，也就是一般電腦的英特爾處理器；系統是 Ubuntu 24.04；ROS 版本是 jazzy；頻道號碼沒設定，就是預設的零號。

拿真車上次實測的結果來對照。真車的架構是 aarch64，也就是手機在用的 ARM 處理器，記憶體八 GB，主機系統是 Debian 12。但是真車的 ROS 是裝在 Docker 容器裡面，容器裡是 Ubuntu 22.04，ROS 版本是 humble，頻道號碼是二十。所以模擬和真車的 ROS 版本不一樣，不過今天會用到的指令，兩個版本幾乎完全相同。我念完以後就開始執行。
