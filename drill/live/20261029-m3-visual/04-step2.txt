第二步，顏色追蹤。請你先準備好那個顏色鮮豔的物品，拿到鏡頭前方大約五十公分。

這一步要開兩個節點。左上角第一格，打 ros2 run yahboomcar 底線 astra 空格 colorHSV。它負責開鏡頭、找顏色，把色塊的中心點送到 Current 底線 point 這個話題。右上角第二格，打 ros2 run yahboomcar 底線 astra 空格 colorTracker，它負責 PID，把中心點換成雲台角度。兩個指令後面都會加一串改名參數：減 r servo 底線 s1 冒號等於 servo 底線 s1 底線 raw，s2 也一樣，速度話題也一樣。意思是官方程式以為自己在指揮雲台，其實指令都先送到守門員那裡。

程式開起來以後，畫面上會出現影像視窗。操作有三個動作，少一個都不會動。第一，在視窗上按小寫 r，進入選色模式。第二，用滑鼠框住物品上單一顏色的一塊，放開滑鼠，右邊會出現黑白遮罩，只有那個顏色是白的。第三，按空白鍵，進入追蹤模式。

為什麼要用 HSV 找顏色？因為紅綠藍三個數字會隨著燈光一起變暗，HSV 把色相和亮度分開，燈光變化影響比較小。

追蹤開始後，請把物品慢慢往左、往右移動。鏡頭會跟著轉，但只會在正前方左右十度內轉。同時看左下角第三格，會一直印出「S1 要求多少、送出多少」，還有「S2 要求多少、已攔下」。

我念完以後就開始執行，框選的動作我會從這邊用滑鼠幫你做。
