## 在另一台電腦接續前：環境檢查

1. `git pull` 這個 repo。
2. WSL 裡要有 ROS 2 Jazzy＋這些套件：`turtlesim demo_nodes_cpp rqt_graph rmw_cyclonedds_cpp rviz2 robot_state_publisher joint_state_publisher_gui tf2_ros tf2_tools ros_gz_sim ros_gz_bridge xacro`，以及指令 `tmux gz dot jq`。
3. **模擬車套件 `microros_pi5_sim` 要自己編**（HP2 原本也沒有）：

   ```bash
   source /opt/ros/jazzy/setup.bash
   mkdir -p ~/yahboom_ws/src
   cp -r /mnt/c/Users/$WINUSER/workspace/yahboom-microros-pi5/sim/microros_pi5_sim ~/yahboom_ws/src/   # $WINUSER 換成 Windows 使用者名稱
   cd ~/yahboom_ws && colcon build --symlink-install
   echo 'source ~/yahboom_ws/install/setup.bash' >> ~/.bashrc
   sudo apt-get install -y jq
   ```

4. 每個終端機都先設定：

   ```bash
   export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
   ```

## W4 從步驟 4 接續

步驟 4 需要 RViz 模型先開著，所以要先把步驟 2、3 的狀態恢復：

```bash
# ① launch 格
ros2 launch microros_pi5_sim display.launch.xml
# 關掉滑桿節點（一定要 -9，一般 kill 會卡住不退）
kill -9 $(pgrep -f "[j]oint_state_publisher_gui")
# ② 輔助格：自己發關節角度，記得帶 stamp: now
ros2 topic pub -r 10 /joint_states sensor_msgs/msg/JointState \
  "{header: {stamp: now}, name: [zq_Joint, yq_Joint, yh_Joint, zh_Joint, jq1_Joint, jq2_Joint], position: [2.5, 2.5, 2.5, 2.5, -0.8, 0.3]}"
```

然後照計畫檔做：

| 步驟 | 指令 | 預期 |
| --- | --- | --- |
| 4 TF | `ros2 run tf2_ros tf2_echo base_link radar_Link`、`tf2_echo base_link jq2_Link`、`ros2 run tf2_tools view_frames` | 光達 z≈0.079；雲台數值隨角度變；產生 TF 樹 PDF（可用 `dot` 轉 PNG） |
| 5 Gazebo | `ros2 launch microros_pi5_sim sim.launch.xml`；`ros2 topic pub /cmd_vel ...`；最後送零速度 | 模擬車轉圈；fixed frame 是 odom，光達紅點不會跟著車轉 |

## 這次踩到的坑（都已解決）

| 狀況 | 原因 | 解法 |
| --- | --- | --- |
| 烏龜按方向鍵不動 | 節點其實有動，是我用 `win32gui.MoveWindow` 搬了 WSLg 視窗，畫面凍結 | 重開節點；**WSLg 視窗只用滑鼠拖，不要用程式搬** |
| `ros2 daemon start` 卡住 | WSL 上 daemon 啟動慢 | 先用 `--no-daemon`，daemon 在背景起來後一般指令就正常 |
| rqt_graph 凍住／空白 | d3d12 GPU 繪圖 | `GALLIUM_DRIVER=llvmpipe ros2 run rqt_graph rqt_graph`（視窗開在第二螢幕） |
| RViz 姿勢 B 不更新、座標軸消失 | 手動發的 `/joint_states` 沒帶時間（stamp=0），TF 當成舊資料丟掉；加上滑桿節點 kill 後沒退出，在搶著發 | `header: {stamp: now}`＋`kill -9` 滑桿節點，10 秒內生效。上次姿勢 B 要等 60 秒很可能也是這個原因 |
| ROS_DOMAIN_ID 等很久 | 上次 15～20 秒 | 這次加上 CycloneDDS＋LOCALHOST，4 秒就收到 |
