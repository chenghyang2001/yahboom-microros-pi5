第三步的結果：ROS 2 工作桌打開了，現在有兩個容器。

先看第三格剛才印的腳本，十二行都在畫面上，第八行確實寫著斜線 tem。

再看右上角第二格。執行 ros2 humble 點 sh 以後，第一行是 access control disabled，clients can connect from any host，這是 xhost 加號的回應，允許容器在桌面開視窗。第二行是 MY DOMAIN ID 冒號 20，這是容器開機時自己印的，意思是這張工作桌用的 ROS 網域號碼是二十。上一單元學過，網域號碼不同的節點互相聽不到；拍五上所有的 ROS 2 程式都約定用二十號。最後，提示字元從 pi 小老鼠 raspberrypi 變成了 root 小老鼠 raspberrypi 冒號斜線，我們已經坐在工作桌前面了。你也會發現第二格上方的標題，被容器改成了 root 小老鼠 raspberrypi，這是容器裡的 bash 自己改的，不影響使用。

最後看第三格的 docker ps，這次有兩行。第一行是 yahboomtechnology 斜線 ros humble，十幾秒前才建立，就是剛打開的工作桌。第二行是 micro ros agent，十一分鐘前建立，是第一步打開的翻譯官。

所以容器的數量，從第一步開始前的零個，變成第一步之後的一個，現在是兩個。拍五開機時三十秒內自動做完的事：翻譯官、小腦連線、工作桌，我們已經一件一件手動做完了。
