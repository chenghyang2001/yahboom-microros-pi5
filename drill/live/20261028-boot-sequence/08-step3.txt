第三步，打開 ROS 2 工作桌容器。

翻譯官和小腦已經接上線了，但是要用 ROS 2 的指令去看、去控制這些話題，需要一張工作桌。這張工作桌就是 Yahboom 做好的 ROS 2 Humble 容器，裡面裝好了 ROS 2 和車子的程式。

這一步分三件事。

第一件，在下面第三格，打 cat 減 n 波浪號斜線 ros2 humble 點 sh，把工作桌的開機腳本印出來。這個腳本有十二行，比較長，所以我會先把第三格拉高一點，上面兩格會暫時變矮。

腳本的重點是這樣的。第二行 xhost 加號，是允許容器在桌面上開視窗。第三行開始是一個很長的 docker run，用反斜線拆成好幾行。減減 privileged 等於 true，給容器完整的硬體權限；減減 net 等於 host，讓容器直接用拍五的網路，這樣它才能跟翻譯官講話；env DISPLAY 是把桌面的位址傳進去；兩個減 v，把手把和攝影機這兩個裝置借給容器用。最後一行是映像檔的名字 yahboomtechnology 斜線 ros humble，冒號 4.1.2，然後執行 bash。

有兩個小地方可以注意。第一，這個 docker run 沒有減減 rm，所以每次離開容器，舊的容器不會被刪掉，會一直留在拍五上，我剛才查到已經累積了十四個。第二，第八行寫的是斜線 tem，應該是斜線 tmp，是原廠腳本的筆誤，會讓容器裡的視窗程式比較難打開，不過今天用不到。

第二件，在右上角第二格，執行 sh 波浪號斜線 ros2 humble 點 sh，真的打開工作桌。預期第二格會先印一行 access control disabled，是 xhost 的回應，接著提示字元會從 pi 小老鼠 raspberrypi，變成 root 小老鼠 raspberrypi，代表你已經在容器裡面了。

第三件，回到第三格打 docker ps，預期這次會看到兩個容器：一個是 micro ros agent，翻譯官；一個是 ros humble，工作桌。

我念完以後就開始執行。
