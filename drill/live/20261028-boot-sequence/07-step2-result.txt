第二步的結果：小腦連上翻譯官了。

你按下 Reset 以後，左上角第一格先出現了一行 session established，握手成功。緊接著刷出一長串綠色的 created，畫面一下子就被洗到最底下了。

我把第一格裡的訊息數了一遍：一個 participant，代表小腦這個參與者；八個 topic，也就是八個話題；四個 publisher，加上四個 data writer，是小腦要「發布」的四種資料，像電池、IMU、光達、里程計；四個 subscriber，加上四個 data reader，是小腦要「訂閱」的四種指令，像速度、蜂鳴器、兩個雲台舵機；還有一個 client，是一個服務。

對照第一步：第一步結束時，第一格只有 running 和 logger setup 兩行，翻譯官在空等。現在它跟小腦接上線，小腦的每一個話題，都由翻譯官在 ROS 2 那一邊開好了。

不過，這些話題現在還沒有人在用，因為 ROS 2 的工作桌容器還沒打開。這就是下一步要做的事。

下一步，第三步，我們先在第三格把工作桌的開機腳本印出來看，然後在第二格把 ROS 2 容器打開，最後用 docker ps 確認現在有兩個容器。等你說繼續。
