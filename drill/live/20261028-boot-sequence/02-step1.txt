第一步，打開翻譯官 agent。

這一步會照順序做三件事。

第一件，在下面第三格打 docker ps，列出正在執行的容器。現在應該只會看到一行標題，下面是空的，證明一個容器都沒有。

第二件，同樣在第三格，打 cat 減 n 波浪號斜線 start agent rpi5 點 sh，把翻譯官的開機腳本印出來，前面會有行號。這個腳本一共五行。第一行告訴系統用 bash 來執行。第二行和第四行是註解。第三行是 Wi-Fi 版本的指令，因為前面有井字號，所以不會執行。真正會執行的是第五行：用 docker run 打開翻譯官容器，透過 USB 序列線 tty USB 零，用每秒九十二萬一千六百個位元的速度，去等小腦 ESP32。

第三件，在左上角第一格，執行 sh 波浪號斜線 start agent rpi5 點 sh，真的把翻譯官打開。

執行以後，你會在第一格看到兩行字。一行寫著 init，running，fd 三，意思是翻譯官已經打開 USB 序列埠，開始在線上等待。另一行寫著 logger setup，是設定紀錄要印多詳細。

這時候小腦還沒有連上來，所以不會出現 created 的訊息，這是正常的，下一步才會處理。

我念完以後就開始執行。
