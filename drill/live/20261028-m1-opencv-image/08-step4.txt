第四步，換成 ROS 的做法：讓相機節點把影像廣播出去。

前面三步，都是程式自己打開相機自己看。可是在機器人上，常常有好幾個程式都想看同一支鏡頭。ROS 的做法是只讓一個相機節點打開鏡頭，把每一幀影像發布到一個話題，誰想看就去訂閱。這有點像電視台：只有一台攝影機在拍，大家各自轉到同一個頻道收看。

先在左上角第一格啟動相機節點，指令是 ros2 run usb cam usb cam node exe。它會打開 斜線 dev 斜線 video 零，然後持續發布影像。第一格會印出相機的設定，例如解析度和像素格式，之後就停在那裡一直跑，這是正常的。

然後到下面第三格做三個檢查。第一個，ros2 topic list，只挑出名字有 image 的話題，預期會看到 image raw。第二個，ros2 topic hz 斜線 image raw，量六秒，看每秒發布幾張影像。第三個，ros2 topic echo 斜線 image raw，加上 減減 once 只看一筆，再加上 減減 no arr，意思是不要印出那一大串像素資料，只看表頭的欄位。預期會看到 height 高、width 寬、encoding 像素格式，還有 step，也就是一列佔多少位元組。

這幾個欄位，就是 ROS 用來描述一張影像的方式，等一下要靠 cv bridge 把它翻譯成 OpenCV 看得懂的數字表格。
