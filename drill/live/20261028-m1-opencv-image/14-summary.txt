今天的總結。

中級第一單元，OpenCV 與 ROS 影像話題，一共六步，車子和雲台全程都沒有動。

第一步，我們看到一張圖在電腦眼中就是一張數字表格。yahboom 範例圖的 shape 是一百六十九、三百四十三、三，先高後寬，每個像素有藍、綠、紅三個數字。3 底線 3 點 py 把它變成灰階和 Canny 邊緣，關閉時官方範例的 img 點 release 會報錯，刪掉那行就好。

第二步，用 OpenCV 直接打開車頭相機，看到貼著地板的廣角即時畫面，按 q 正常關閉，相機乾淨地還給系統。

第三步，QR code 辨識這次沒有成功，只誤讀到一個一維條碼。相機低、畫面小、光線暗都是可能原因，留到 M3 再調整距離和光線。

第四步，換成 ROS 的做法。usb cam 相機節點把影像發布到 image raw，每秒約二十九點八張，寬六百四十、高四百八十，格式是 yuv422，不是 OpenCV 習慣的藍綠紅。

第五步證明了一支鏡頭只能給一個程式用。相機節點開著時，再用 OpenCV 開鏡頭，得到的是「編號超出範圍」這種容易誤導人的錯誤。

第六步，pub image 訂閱 image raw，用 cv bridge 翻譯成藍綠紅、再翻譯回 ROS 訊息，發布到 image，速度幾乎沒掉，最後在 rqt image view 看到即時畫面。

一句話記住今天：鏡頭只讓相機節點開一次，其他程式都去訂閱話題，cv bridge 負責在 ROS 影像和 OpenCV 數字表格之間翻譯。

電池目前是七點四伏特，還很充足。演練到這裡結束，謝謝收看。
