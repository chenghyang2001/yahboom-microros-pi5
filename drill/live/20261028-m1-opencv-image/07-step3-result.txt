第三步，QR code 辨識這次沒有成功，我們先跳過。

看第一格，程式確實有跑起來，相機也打開了，可是從頭到尾只印出一行：Found I25 barcode，內容是八八零六二二。I25 不是 QR code，是一種只有黑白直條的一維條碼，可能是紙上或旁邊某個條碼被認出來了，或者是誤判。手上那張紙的 QR code 一直沒有被讀到。

可能的原因有幾個。第一，相機裝得很低、又是廣角，紙要拿得很近、很正，QR code 在畫面裡才夠大。第二，視窗左上角的 FPS 只有個位數，畫面一晃就糊掉。第三，室內光線偏暗，紙面反光也會影響。之後 M3 要用 QR code 控車時，再專門把距離和光線調好。

我已經按 q 關掉程式，相機也釋放了。

接下來進入後半段，換成 ROS 的做法。下一步會在第一格啟動 usb cam 相機節點，讓它把影像廣播到 image raw 話題，再到第三格檢查這個話題。等你說繼續。
