第一步的結果出來了。

先看第一格印出的第一組數字：一百六十九、三百四十三、三。意思是這張圖高一百六十九個像素、寬三百四十三個像素、每個像素有三個顏色通道。再提醒一次，是先高後寬。

第二組數字是兩百五十五、兩百五十五、兩百五十五。第一百列、第一百行剛好落在白色背景上，藍綠紅三個數字都是最大值，合起來就是白色。所以對電腦來說，這張圖就是一張高一百六十九、寬三百四十三、每格放三個數字的大表格。

接著跑 3 底線 3 點 py，桌面跳出了三個視窗。中間是灰階圖，原本三個數字被壓成一個亮度，視窗底下顯示 L 等於兩百五十五，L 就是亮度。右上角是 Canny 邊緣圖，整張變成黑底，只剩下 yahboom 字母和小機器人的輪廓是白線，因為只有顏色變化劇烈的地方才算邊緣。原圖視窗被壓在灰階圖下面，只露出底部一行 R、G、B 都是兩百五十五。

最後我在視窗上按 q 離開，第一格果然跳出 AttributeError，說 numpy 陣列沒有 release 這個方法。原因是官方範例最後一行寫了 img 點 release，可是 img 只是一張圖片的數字表格，不是攝影機，沒有 release 可以呼叫。這不影響結果，自己寫程式時刪掉那一行就好。
