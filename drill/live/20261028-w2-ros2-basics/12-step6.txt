第六步，看全貌：rqt graph 關係圖，和 launch 檔。

節點和話題一多，腦袋很難記住誰連到誰。這一步分成兩個部分。

第一部分，在下面第三格執行 ros2 run rqt graph rqt graph。會跳出一個新視窗，畫出一張關係圖：圓框是節點，箭頭上的字是話題。你應該會看到遙控器 teleop turtle，透過 turtle1 cmd vel 這個話題，箭頭指向烏龜節點 turtlesim。這就是我們前面一直在操作的那條資料流。我會讓關係圖停留一會兒，然後把它關掉。

第二部分，是 launch 檔。真正的機器人一次要開好幾個節點，一個一個打 ros2 run 太累了。launch 檔就像一份開工清單，一個指令就能把清單上的節點全部叫起來。

所以我會先把第一格的烏龜和第二格的遙控器，都按 Ctrl C 關掉，原本的烏龜視窗會消失。接著在第一格執行 ros2 launch turtlesim multisim 點 launch 點 py。這一個指令，會同時開出兩個烏龜視窗。

最後在第三格打 ros2 node list，你會看到兩個烏龜節點，名字前面分別多了 turtlesim1 和 turtlesim2，這叫做命名空間，用來區分兩個同樣的程式。

對應到拍五：車上大量使用 ros2 launch。例如手把控制，就是一個 launch 檔，同時啟動手把驅動節點和控車節點。

我念完以後就開始執行。
