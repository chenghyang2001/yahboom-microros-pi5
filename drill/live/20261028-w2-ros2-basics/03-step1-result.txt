第一步的結果：兩個節點都叫出來了，也看到了烏龜的名片。

先看左上角第一格。執行 turtlesim node 以後，印出兩行 INFO：一行說節點名稱叫 turtlesim，另一行說在座標五點五、五點五的位置生出了一隻叫 turtle1 的烏龜。螢幕右邊的藍色視窗，就是這個節點畫出來的。

再看右上角第二格，鍵盤遙控器已經在等方向鍵了，上面寫著用方向鍵移動烏龜，按 q 離開。我送了一串方向鍵進去，你可以看到烏龜已經離開正中間，往右邊走了一段。

接著是下面第三格。這裡出了一個小插曲：第一次打 ros2 node list 的時候卡住沒有反應。原因是 ROS 2 會在背景開一個小幫手，叫做 daemon，專門記住現在有哪些節點，第一次要先把它叫起來，這次它沒有自己起來。我另外把它啟動以後，再打一次就正常了。

ros2 node list 列出了兩個名字：teleop turtle 和 turtlesim，就是剛才那兩個員工。

ros2 node info 斜線 turtlesim 印出了一張很長的名片。最上面的 Subscribers，是它在聽的話題，裡面有速度指令 turtle1 cmd vel，型別是 Twist。Publishers 是它在說的話題，有烏龜的位置 pose 和顏色感測。再下面的 Service Servers 是它提供的服務，有 spawn、clear、kill 等等。最後還有 Action Servers，是動作，例如讓烏龜轉到指定角度。因為第三格不夠高，畫面上只看得到後半段的服務和動作。
