第二步，話題：偷聽烏龜的對話。

話題就像公司的群組聊天，有人在群組裡說話，誰想知道就加入那個群組旁聽。遙控器和烏龜之間，就是透過一個話題在溝通。這一步全部在下面第三格操作，一共五個指令。

第一個，ros2 topic list，列出所有話題。你會看到五個，其中 turtle1 斜線 cmd vel 是速度指令，遙控器往這裡說，烏龜在這裡聽。

第二個，ros2 topic echo 斜線 turtle1 斜線 cmd vel，意思是加入這個群組當旁聽者。接著我會在第二格送方向鍵，你會看到第三格一筆一筆跑出速度資料：按上，linear 的 x 是二，代表往前走；按左，angular 的 z 是二，代表往左轉。看完我會按 Ctrl C 停止旁聽。

第三個，ros2 topic info，看這個話題的型別，還有幾個發布者、幾個訂閱者。發布者是遙控器，訂閱者是烏龜，各一個。

第四個，ros2 topic hz 斜線 turtle1 斜線 pose，量烏龜位置這個話題每秒發幾次，大約六十次。

第五個，ros2 interface show geometry msgs 斜線 msg 斜線 Twist，看速度訊息的格式。Twist 分成兩組：linear 是直線速度，angular 是旋轉速度，各有 x、y、z 三個值。兩輪或四輪的車，只會用到 linear 的 x，前進後退，和 angular 的 z，左轉右轉。

好消息是，拍五的速度話題 cmd vel，用的也是同一種 Twist。在烏龜身上學會的，可以原封不動用在車上。

我念完以後就開始執行。
