總結：暖身第二單元，ROS 2 最小必學。

今天我們在電腦的 WSL 上，用一隻小烏龜，把 ROS 2 最核心的觀念全部走了一遍。

第一步，節點。ros2 run 叫出烏龜和遙控器兩個節點，ros2 node list 列出它們，ros2 node info 看烏龜的名片。

第二步，話題。ros2 topic list 列出話題，ros2 topic echo 旁聽遙控器對烏龜說的速度，ros2 topic info 和 hz 看型別和頻率，interface show 看 Twist 的格式：linear 和 angular。

第三步，自己發話題。ros2 topic pub 讓烏龜一直轉圈，這是本單元的過關題。

第四步，服務。ros2 service call 生出第二隻烏龜，清掉軌跡，再把牠刪掉。話題是一直廣播，服務是一問一答。

第五步，參數。ros2 param set 把背景改成紫紅色，param dump 把設定單存成檔案。

第六步，看全貌。用文字確認遙控器透過速度話題連到烏龜，再用一個 launch 指令開出兩隻烏龜，認識命名空間。

第七步，ROS DOMAIN ID。同一個號碼聽得到，不同號碼聽不到；而且程式之間要花一點時間才能互相找到。

最重要的一句話：烏龜的 turtle1 cmd vel 和拍五的 cmd vel，用的是同一種 Twist。今天在烏龜身上學會的每一個指令，之後都可以原封不動搬到車上。

這次演練也遇到幾個狀況：鍵盤的方向鍵一開始沒送到遙控器、烏龜視窗太小被切掉、圖形化的關係圖在 WSL 上顯示不出來，還有聽的人要多等一會兒才收得到。這些都已經記錄下來，下次會先避開。

演練到這裡結束，接下來我會停止錄影。謝謝收看。
