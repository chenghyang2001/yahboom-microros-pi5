第二步的結果：我們成功偷聽到遙控器對烏龜說的話。

先說一個插曲。第一次做的時候，我送進第二格的方向鍵，遙控器沒有收到，所以旁聽的畫面是空的。後來查出是送按鍵的方式不對，改正以後重做了一次。這也提醒我們：鍵盤遙控沒反應，通常是按鍵沒有真的送到遙控器那個視窗，平常用滑鼠的時候，就是要先點一下那個終端機。

再來看結果。ros2 topic list 列出了五個話題：parameter events 和 rosout 是系統內建的，另外三個是烏龜的：cmd vel 是速度指令，color sensor 是顏色感測，pose 是位置。

ros2 topic echo 旁聽 cmd vel 的時候，我按了兩次左、三次上。第三格一筆一筆跑出了速度資料：按上的時候，linear 的 x 是二，其他都是零，代表往前走；按左的時候，angular 的 z 是二，代表往左轉。螢幕右邊的烏龜也照著轉彎、往前走，畫出了一條路線。

ros2 topic info 告訴我們，這個話題的型別是 Twist，發布者一個，就是遙控器；訂閱者一個，就是烏龜。

ros2 topic hz 量出烏龜位置這個話題，每秒大約發六十二次。

最後，ros2 interface show 印出了 Twist 的格式：linear 和 angular 兩組，各有 x、y、z。

記住這個對照：烏龜的 turtle1 cmd vel，和拍五的 cmd vel，用的是同一種 Twist。

下一步，第三步，我們不用遙控器，自己在群組裡說話，讓烏龜一直轉圈，這是本單元的過關題。等你說繼續，我會先念第三步的說明。
