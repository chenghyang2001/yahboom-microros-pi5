第一步，Linux 終端機的基本指令。

Linux 的終端機，就像跟電腦對話的對講機：你打一行字，它回一段結果。先記住一件事：你永遠「站」在某一個資料夾裡。這一步在下面第三格，依序打四個指令。

第一個，pwd，print working directory，印出我現在站在哪個資料夾。預期是斜線 home 斜線 pi，這是 pi 這個帳號的家目錄，也可以用一個波浪號代表。

第二個，ls，list，列出這個資料夾裡有什麼。預期會看到二十幾個項目，其中兩個你已經很熟了：start agent rpi5 點 sh，翻譯官的開機腳本；ros2 humble 點 sh，工作桌的開機腳本。旁邊還有兩個同名、後面多了點 ori 的檔案，那是原廠的備份。另外還有一個 voice 資料夾，是我們自己做的語音指令程式。

第三個，ls 斜線 dev 斜線 tty USB 星號。星號是萬用字元，代表「後面接什麼都可以」，所以這行是：列出所有 tty USB 開頭的裝置。預期只有一個，tty USB 零，就是通往小腦的序列線。如果哪天這裡是空的，代表小腦的 USB 線鬆了，翻譯官一定連不上。

第四個，hostname 減大寫 I，看這台機器的 IP 位址。預期第一個是 10.169.179.1，這是車子在手機熱點裡的位址；第二個 172.17.0.1，是 Docker 自己內部用的網路。

最後教兩個救命按鍵，今天會用到：Tab 鍵，打一半按下去會自動補完檔名；Ctrl C，中斷正在跑的程式，在 ROS 裡停止一個節點就靠它。

我念完以後就開始執行。
