第一步的結果，四個指令都在下面第三格。

pwd 印出斜線 home 斜線 pi，我們站在家目錄。

ls 列出了二十二個項目，用顏色分類：藍色的是資料夾，像 Desktop、Documents、voice、wifi fallback；綠色的是可以執行的檔案，像兩個開機腳本 start agent rpi5 點 sh、ros2 humble 點 sh，還有它們的備份點 ori；白色的是一般檔案。光是看顏色，就能分出哪些是資料夾、哪些能執行。

ls 斜線 dev 斜線 tty USB 星號，只找到一個：tty USB 零。通往小腦的序列線好好的。

hostname 減大寫 I 印出三個位址：10.169.179.1 是車子在手機熱點裡的位址，也是我們等一下 SSH 連進來的地方；172.17.0.1 是 Docker 的內部網路；最後一長串有冒號的，是 IPv6 位址，可以先不用管。

這四個指令看起來很簡單，但除錯時最常用：pwd 確認自己在哪，ls 確認檔案在不在，ls dev 確認硬體有沒有被認到，hostname 減 I 確認網路位址。
