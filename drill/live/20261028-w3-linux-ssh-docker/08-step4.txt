第四步，用 docker exec 開第二個終端機，走進同一個容器。

先說一個新手最常犯的錯。右上角第二格已經在工作桌裡了，如果我想再開一個終端機也進工作桌，直覺會再跑一次 ros2 humble 點 sh。但那會「再蓋一棟新房子」，兩棟房子各自獨立，第二個終端機就看不到第一個終端機開的程式。正確的做法是 docker exec：走進已經在跑的那一棟。

這一步在下面第三格，依序做四件事。

第一件，docker exec 減 i t，後面接容器 ID，再接 bash。減 i 是保持輸入、減 t 是給一個終端畫面，合起來就是「讓我進去打字」。容器 ID 不用打完整的十二碼，只要打前幾碼，能分辨出是哪一個就好。上一步看到工作桌的 ID 是 e f 5 6 開頭，我就打 e f 5 6。預期第三格會印出 MY DOMAIN ID 二十，提示字元從 pi 小老鼠，變成 root 小老鼠。

第二件，在裡面打 ros2 node list。講義這裡標著「需實車確認」：docker exec 進來的終端機，能不能直接用 ros2 指令，還是要先 source 一次環境？預期可以直接用，會看到 YB Car Node。

第三件，打 exit，離開容器。提示字元會變回 pi 小老鼠。注意，因為我們是 exec 進去的第二個終端機，離開時工作桌不會停，右上角第二格完全不受影響。

第四件，再打一次 docker ps，確認容器還是兩個，沒有多蓋一棟新房子。

我念完以後就開始執行。
