第二步，SSH：我現在到底是怎麼連進這台車的。

SSH 是 Secure Shell，加密的遠端終端機。你在自己的電腦打字，指令卻在車上的樹莓派執行。講義的寫法是 ssh pi 小老鼠 車子的 IP，登入帳號是 pi。整場演練，我送進這三格的每一個指令，都是透過 SSH 送進來的；而你在螢幕三看到的桌面，是另一條連線，叫 VNC，遠端桌面。

我們的接法有點特別。電腦和車子不在同一個網路，電腦是用 USB 線接著手機，手機開熱點，車子連上手機的熱點。所以一條連線要走四段：電腦，經過 USB 線，到手機，手機再經過 Wi Fi 熱點，到樹莓派。手機在中間扮演轉接站的角色。

我們用指令來證明。在下面第三格打：ss 減 t n，sport 等於冒號 22，or，sport 等於冒號 5900。ss 是 socket statistics，列出網路連線；減 t 是只看 TCP，減 n 是用數字顯示；後面的條件是：只看本機這端是 22 號門或 5900 號門的連線。22 號門是 SSH，5900 號門是 VNC。

預期會看到兩行 ESTAB，也就是已建立的連線。左邊 Local Address 是車子自己，10.169.179.1；右邊 Peer Address，對方，預期是 10.169.179.82，那就是手機在熱點裡的位址。這證明了：從車子的角度看，連進來的不是電腦，而是手機。

我念完以後就開始執行。
