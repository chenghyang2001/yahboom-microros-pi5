第四步，在節點執行中即時修改參數，再測試光達斷線保護。

這一步主要在最下面第三格下指令，中間第二格看節點的反應。

第一個指令，ros2 param set 斜線 obstacle stop，scan timeout，一點零。把「多久沒收到光達就停車」從零點五秒放寬到一秒。注意要寫一點零，不要寫一，因為這個參數是小數，型別不對會設定失敗。預期第三格回應 Set parameter successful，之後第二格的黃色警告應該會變少或消失。

第二個指令，ros2 param set 斜線 obstacle stop，stop distance，零點二。停車距離從零點三改成零點二。車子現在離牆零點三公尺，比零點二加上遲滯距離零點零五，也就是零點二五，還要遠，所以節點會判定前方淨空。預期第二格印「前方淨空零點三零公尺，繼續前進」，車子再往前走一點點，接著印「前方零點一九公尺有障礙，停車」。我們不用改程式、不用重新編譯，參數馬上生效，因為程式每次計時器觸發都會重新讀參數。接著我再印一次 odom 的位置，x 應該從一點一五增加到大約一點二五。

最後測試斷線保護。我在最上面第一格按 Ctrl C，關掉模擬車，光達的 scan 就斷了。預期第二格大約一秒後印出黃色警告：超過一點多秒沒收到 scan，先停車。這就是光達斷線時，節點不會瞎開。

看到警告後，我在第二格按 Ctrl C 結束節點。程式結束前會送出一個零速度，所以應該會乾淨地結束、回到提示字元。

我念完以後就開始執行。
