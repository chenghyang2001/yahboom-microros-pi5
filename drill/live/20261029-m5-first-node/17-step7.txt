第七步，落地測試，這是今天的最後一個實驗。車子現在放在地上，前方大約一公尺有紙箱。

右上第二格的限速閥還開著，不用重開。我只要在左上第一格，按向上鍵叫出剛才的指令，也就是 ros2 run my obstacle stop obstacle stop，加上 remap 到 cmd vel raw，再執行一次。

預期會這樣：節點啟動後，車子以每秒零點一公尺往前走，一公尺的距離扣掉三十公分，大約七秒會走到。第一格印出「前方零點二幾公尺有障礙，停車」，車子在紙箱前大約三十公分停下。真車有慣性，可能會比模擬車多滑一點點。

車子停下以後，我會播一句提示，請你把紙箱拿開。拿開後第一格應該印「前方淨空，繼續前進」，車子再往前走。走大約三秒，我就在第一格按 Ctrl C 停車，不讓它跑出空地。

安全方面，萬一車子走了十五秒還沒停，我也會直接按 Ctrl C。你也可以隨時把車拿起來。

我念完以後就開始執行。
