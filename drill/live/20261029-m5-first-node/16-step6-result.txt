第六步的結果，架高測試全部通過。

在車上的容器裡，colcon build 不到三秒就完成。中間印了一段 stderr，是 setuptools 說 setup py install 這種安裝方式已經過時，只是警告，最後一樣是 Finished。

節點啟動後，左上第一格一共記錄了五次停車、五次繼續前進。第一次是零點二九公尺停車、零點三七公尺繼續，跟設計完全一樣。中間有一段在一秒內連續停、走、停，距離是零點一三和零點六一交替，那是手剛好從光達掃描範圍的邊緣快速進出，手一下在扇形裡、一下在扇形外，遲滯擋不住這種情況。最後一次是零點二公尺停車、零點六一公尺繼續。

接著你把手放在車子後方，我在前後各數了一次，十八秒內停車次數維持五次，一次都沒有增加。這證明節點只看正前方，而且光達的零度確實是車頭，角度修正參數不用改。

最後我在第一格按 Ctrl C，節點直接回到提示字元，沒有錯誤訊息。右上第二格的限速閥也印出一行黃色警告：「看門狗，零點五秒沒收到 cmd vel raw，已送零速度」。所以車子有兩層保護：節點結束前自己送零，限速閥再補送一次零。輪子應該已經停了，請你看一下確認。

下一步是落地測試。請你把車從盒子上拿下來，放在那一點五公尺直線空地的一端，車頭朝向空地，前方大約一公尺放紙箱。準備好以後說繼續。
