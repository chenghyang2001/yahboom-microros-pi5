第五步，把套件從電腦搬到真車。從這一步開始是後半場。

先在電腦 WSL 的第三格做兩件事。

第一個指令，cd 到 m5 底線 ws 斜線 src，用 tar 減 c z f 把 my obstacle stop 整個資料夾打包成一個壓縮檔，減減 exclude 雙底線 pycache，把 Python 自動產生的快取排除掉。打包完用 ls 看一下，檔案應該只有幾 KB。

第二個指令，scp 減大寫 P 八零二二，把壓縮檔傳到 pi 小老鼠 127 點 0 點 0 點 1 的家目錄。為什麼是 127 點 0 點 0 點 1、port 八零二二？因為我們的電腦是透過 USB 接手機，手機再用熱點連到車子，八零二二這個 port 會被轉接到車子的 SSH。講義裡寫的是車子熱點的 IP，意思一樣，只是連線路線不同。第一次連線會自動記下車子的身分，接著問密碼，我會輸入出廠預設的密碼，輸入時畫面不會顯示。傳完會看到一行百分之一百。

接下來畫面會切換到 Pi 5 的 VNC 桌面。上面是車上的 tmux，一樣分三格。左上第一格和右上第二格，都已經用 docker exec 進到 ROS 2 容器裡，提示字元是「容器」。下面第三格留在 Pi 主機，提示字元是「Pi 主機」。

在 Pi 主機的第三格做三件事。第一，建立 my ws 斜線 src，用 tar 減 x z f 把壓縮檔解開到裡面。第二，用 docker ps 減 q 加上 filter，找出 ROS 2 容器的 ID，存進變數 C。一定要用 filter 篩選映像檔，因為車上還有另一個 micro ROS agent 容器，不能搞錯。第三，用 docker cp 把整個 my ws 複製進容器的 root 資料夾，再把上一場用過的限速閥程式 cmd vel limiter 點 py 也複製進去。

最後在第一格的容器裡用 ls 確認，看得到 my obstacle stop 和限速閥兩樣東西，就代表搬家完成。

我念完以後就開始執行。
