第二步，把講義寫好的程式放進骨架，並且看懂它的結構。

一樣在最下面第三格。第一個指令是 cp，把事先準備在 m5 底線 src 資料夾裡的三個檔案複製進去：obstacle stop 點 py 蓋掉內層那支空殼，setup 點 py 和 package 點 xml 蓋掉外層自動產生的版本。這三個檔案的內容和講義一字不差。

接著用 grep 只挑出程式裡的骨架行，也就是 def 開頭的函式、declare parameter 宣告參數，還有 create 開頭的三個建立動作。整支程式一百一十八行，這樣挑出來大約十五行，剛好看得到全貌。

你會看到程式分成三塊。

第一塊是建構函式 init。它宣告六個參數，例如停車距離 stop distance 零點三公尺、前進速度 forward speed 零點一、只看正前方左右各十五度、超過零點五秒沒收到光達就停車。做成參數的好處是，之後不用改程式就能調。然後建立三樣東西：訂閱 scan 的訂閱者、發布 cmd vel 的發布者，還有一個每零點一秒觸發一次的計時器。

第二塊是 scan callback，光達每送來一圈資料就被呼叫一次，它只做一件事：挑出正前方扇形裡最近的距離，存起來。

第三塊是 control loop，計時器每零點一秒呼叫一次，拿最近距離跟停車距離比，決定送前進速度還是零速度。收資料和做決定分開，是寫控制程式很重要的習慣。

最後我會清掉畫面，再用 grep 印出 setup 點 py 裡的 entry points。那一行的意思是：指令名稱叫 obstacle stop，執行的是套件裡 obstacle stop 這個檔案的 main 函式。等一下 ros2 run 的第二個字，就是從這裡來的。

我念完以後就開始執行。
