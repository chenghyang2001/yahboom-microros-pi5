第五步的結果，搬家一次就成功。

在電腦 WSL 這邊，壓縮檔只有三千八百五十九個位元組，不到四 KB，因為我們的套件就是幾個純文字檔。scp 第一次連線時印了一行 Warning，說已經把車子的身分永久加入 known hosts，這是正常的。輸入密碼後，傳輸顯示百分之一百。

畫面已經切換到 Pi 5 的 VNC 桌面。下面第三格是 Pi 主機。解壓縮以後，ls 看到 my obstacle stop。docker ps 找到 ROS 2 容器的 ID 是 cc8a 開頭。兩個 docker cp 都印出 Successfully copied，一個是整個工作空間，十九點五 KB，一個是限速閥，十點二 KB。

左上第一格在容器裡用 ls 確認，看得到 cmd vel limiter 點 py，也看得到 my obstacle stop 套件裡的五樣東西：內層資料夾、package xml、resource、setup cfg、setup py，還有 test 資料夾。注意這裡沒有 build 和 install 資料夾，因為我們只搬了原始碼。電腦上是 Jazzy，車上容器是 Humble，編譯出來的東西不能共用，所以要在車上重新編譯。

要提醒一件事：容器是暫時的。如果之後重新執行 ros2 humble 點 sh，開出的是一個全新的容器，裡面沒有這些檔案，要再 docker cp 一次，或者用 docker commit 存成新映像。

下一步，在容器裡編譯，啟動限速閥和我們的節點，先把車子架高、讓輪子懸空，再用手測試。請你先準備好架高用的盒子。等你說繼續。
