今天的總結。

中級第五單元，寫自己的第一個控制節點，一共七步，前四步在電腦的模擬車，後三步在真車。

第一步，用 ros2 pkg create 建立 ament python 套件，一次產生 package xml、setup py、setup cfg、resource 和節點空殼。套件名稱在好幾個地方都要完全一致。

第二步，放入講義的程式，看懂三塊結構：init 宣告參數、建立訂閱、發布和計時器；scan callback 只負責收資料、挑出正前方最近的距離；control loop 每零點一秒做一次決定。entry points 決定了 ros2 run 的第二個字。

第三步，colcon build、source、ros2 run，模擬車往前走，在牆前零點三零公尺停下，odom 證明它走了一點一五公尺。過程中 ros2 的 daemon 卡住過一次，重開就好；Gazebo 畫面在 WSL 上不會更新，改用數字證明。

第四步，ros2 param set 即時修改參數，停車距離改零點二，車子再往前十二公分，停在零點一八。關掉模擬車，節點持續警告沒收到 scan、一直送零速度。

第五步，tar 打包、scp 傳到 Pi、docker cp 複製進容器。只搬原始碼，因為電腦是 Jazzy、車上是 Humble，要在車上重新編譯。

第六步，車子架高，用 remap 把速度改名送到限速閥。手放正前方會停、移開會走；手放後方不會停，證明光達零度就是車頭；按 Ctrl C，節點和限速閥兩層都會送零速度。

第七步，落地測試，車子以每秒零點一公尺前進，在紙箱前零點二九公尺停下，紙箱拿開後繼續走。

一句話記住今天：機器人程式的骨架就是「訂閱感測器、做判斷、發布動作」，收資料和做決定分開，數字做成參數，任何異常都先送零速度。

電池目前是七點二伏特。演練到這裡結束，謝謝收看。
