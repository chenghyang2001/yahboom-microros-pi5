第六步，在車上的容器裡編譯，然後架高測試。車子現在應該已經放在盒子上，四個輪子懸空。

第一個動作在右上角第二格：python3 cmd vel limiter 點 py，啟動上一場用過的限速閥。它從 cmd vel raw 收速度，線速度超過零點一五、角速度超過零點八就夾住，再送到真正的 cmd vel 給底盤。零點五秒沒收到新指令，它會自動補送零速度。我們的節點只送零點一，本來就在範圍內，限速閥在這裡是保險。

第二個動作在左上角第一格，分三個指令。cd 到 root 斜線 my ws，colcon build 減減 packages select my obstacle stop。這次沒有加 symlink install，車上不會改程式，用一般安裝就好。編譯完 source install 斜線 setup 點 bash。最後 ros2 run my obstacle stop obstacle stop，後面加上減減 ros args 減 r 斜線 cmd vel 冒號等於斜線 cmd vel raw。減 r 是 remap，重新命名：程式裡寫的是發布到 cmd vel，我們在啟動時把它改名成 cmd vel raw，速度就會先經過限速閥。程式一行都不用改。

節點一啟動，前方沒有東西，輪子就會開始以零點一的速度慢慢轉。

接著請你動手測試。第一，把手放在光達正前方大約二十公分，第一格應該印「前方零點二幾公尺有障礙，停車」，輪子停。第二，把手移開，應該印「前方淨空，繼續前進」，輪子再轉。這兩個可以多做幾次。上一場我們已經確認過，這台車光達的零度就是車頭，所以角度修正參數維持零就好。

我在背景監看第一格，看到停車和繼續前進都出現以後，會再提醒你做下一個測試。

我念完以後就開始執行。
