第二步，看 EKF 拿了什麼、輸出了什麼，再問 TF「車子現在在哪」。這一步車子不會動。

EKF 是擴展卡爾曼濾波器，聽起來很難，但只要看懂一件事：它像一個裁判，同時聽兩個證人說話。輪子說：我轉了幾圈，所以車子走了多遠、轉了多少。陀螺儀說：我感覺到車子轉了多少。輪子在打滑時會說錯，陀螺儀時間久了會飄，EKF 依照兩個人平常的可信度，綜合出一個比較準的答案。

設定檔裡寫明了：從輪子的 odom raw 拿位置、速度和轉向；從陀螺儀的 imu 斜線 data，只拿轉向角和轉向速度。而且是二維模式，因為車子在地上跑，不會飛起來。

右上角第二格，第一個指令，ros2 node info 斜線 ekf filter node。預期 Subscribers 裡看到 imu 斜線 data 和 odom raw，兩個證人；Publishers 裡看到 odom，裁判的判決，還有 tf，座標轉換。

第二個指令，ros2 run tf2 ros tf2 echo，odom，base footprint。意思是：從出發點 odom 看過去，車子底盤 base footprint 現在在哪裡。它每秒印一次 Translation，三個數字是 x、y、z。bringup 剛啟動時，EKF 把車子當下的位置當成原點，所以預期 x、y 都接近零；車子靜止，數字應該幾乎不動。我讓它印幾秒鐘，再按 Ctrl C 停掉。

我念完以後就開始執行。
