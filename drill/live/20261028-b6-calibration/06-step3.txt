第三步，線速度校準。車子會往後倒退，請注意車子後方。

校準的想法很簡單：叫車子走一段距離，再拿捲尺量它真的走了多少。

校準程式叫 calibrate linear，我在右上角第二格啟動它，後面加上減減 ros args 減 p speed 冒號等於 0.1，把速度從原本的每秒五十公分，降到每秒十公分。程式啟動後不會馬上動，要把一個叫 start test 的參數打勾才會開始。講義是用 rqt reconfigure 這個視窗去勾，我們改用一行指令做同樣的事：ros2 param set 斜線 calibrate linear start test true。

接著，程式會做這件事：每零點一秒問一次 TF，「我離出發點多遠」，把這個距離乘上一個比例係數，預設是 1.5，再跟目標一公尺比。還沒到，就繼續走；差距小於三公分，就停車，自己把 start test 取消。

這裡有兩個從原始碼讀到的重點。第一，它用「距離減一公尺」的正負號決定方向，一開始是負的，所以車子會倒退，不是前進。第二，因為係數是 1.5，車子以為的距離乘上 1.5 等於一公尺時就停，也就是車子自己算的里程大約零點六七公尺時停。

所以預期：車子用很慢的速度往後退大約七秒，停下來。右上角第二格會一直印出 error，從負的 1 慢慢變成接近 0。

車子停下以後，請你用捲尺量：從膠帶起點，到車輪現在的位置，實際退了幾公分，然後告訴我。我同時會用 TF 讀出車子自己以為退了多少，兩個一比，就知道誤差。

為了安全，我在背景加了一個時間上限：如果二十秒還沒停，我會強制取消並送零速度。

我念完以後就開始執行。
