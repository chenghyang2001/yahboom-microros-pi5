初級 B2

開機連線：熱點、WiFi、VNC、SSH

⏱ 45 分鐘🚗 真車：是
🎯 學習目標
讓 Windows 電腦連上車子的熱點，用 VNC 看到 Pi 5 桌面、用 SSH 登入終端機，並學會把車改連家裡的 WiFi
✅ 完成標準
電腦連上 Micro_ros 熱點後，VNC Viewer 連 10.42.0.1 看到 Pi 5 桌面，SSH 以 pi／yahboom 登入並執行 hostname -I 看到 IP

1. 為什麼要「遠端」連到車上

🔊 旁白文字

這台車的樹莓派裝在車殼裡面，沒有螢幕、沒有鍵盤。要叫它做事，我們得從自己的電腦「遠端」連進去。遠端有兩種方式。VNC 像是視訊通話，把樹莓派的整個桌面畫面傳到你的電腦上，看得到視窗、可以用滑鼠點。SSH 像是打電話，只傳文字，你打指令、它回結果，速度快又省資源。初學時兩個都會用到：要看圖形畫面，例如攝影機或節點關係圖，就用 VNC；只是打指令，就用 SSH。

方式 傳什麼 適合 Windows 端工具
VNC 整個桌面畫面 看 rqt、rviz2、攝影機畫面，操作開機自動開的兩個終端機 RealVNC Viewer
SSH 純文字終端機 打指令、看 log、傳檔 Windows 10／11 內建的 ssh 指令

不管哪一種，前提都是電腦和車在同一個區域網路（LAN）。出廠的車子會自己開一個 WiFi 熱點，電腦連上這個熱點，兩邊就在同一個網路裡了。

2. 先裝好 VNC Viewer（連熱點前做）

🔊 旁白文字

有一個小陷阱要先講：電腦一旦連上車子的熱點，就上不了網了，因為車子的熱點並沒有接到外面的網路。所以 VNC Viewer 一定要趁電腦還連著家裡網路時先下載安裝好。官方影片也特別提醒這一點。安裝過程一直按下一步就可以，打開後可以選擇不登入帳號直接使用。

  1. 用瀏覽器到 RealVNC 官網下載 Windows 版 VNC Viewer：https://www.realvnc.com/en/connect/download/viewer/
  2. 以系統管理員身分執行安裝檔 → OK → Next → 同意授權 → 完成。
  3. 打開 VNC Viewer，可以選「不登入直接使用」（官方影片 hq0Zbi7BmFA 的作法）。

同時確認 Windows 的 SSH 用戶端可以用（Windows 10 1809 以後內建）：

在 Windows
ssh -V

看到 OpenSSH_for_Windows_... 就表示可以用。

3. 連上車子的熱點

🔊 旁白文字

現在打開車子電源，等大約三十秒讓樹莓派開機。開好之後，車子會廣播一個叫 Micro 底線 ros 的 WiFi。用電腦的 WiFi 清單連上它，密碼是一二三四五六七八。連上之後，車子在這個網路裡的地址固定是十點四十二點零點一，這個號碼請背起來，接下來 VNC 和 SSH 都要用它。

出廠預設值（官方 First Trial 文件與說明書「快速上手使用」頁）：

項目 值
熱點名稱（SSID） Micro_ros
熱點密碼 12345678
熱點模式下 Pi 5 的 IP 10.42.0.1
系統帳號 pi
系統密碼 yahboom
  1. 打開車子擴展板電源，等約 30 秒。
  2. Windows 右下角 WiFi 圖示 → 選 Micro_ros → 輸入 12345678 → 連線。
  3. Windows 可能提示「沒有網際網路」，這是正常的。

確認電腦拿到熱點分配的 IP、而且連得到車子：

在 Windows
ipconfig
ping 10.42.0.1

ipconfig 的 WiFi 介面應該出現 10.42.0.x 開頭的 IPv4 位址；ping 有回應就代表網路通了。

ℹ️ 補充

官方影片口述把熱點唸成「MicroROS」，但文件與說明書都寫 Micro_ros；以你 WiFi 清單裡實際看到的名稱為準。

4. VNC：看到 Pi 5 的桌面

🔊 旁白文字

打開 VNC Viewer，在上面的位址列輸入十點四十二點零點一，按 Enter。第一次連會跳出一個安全提示，按繼續就好。接著輸入帳號 pi、密碼 yahboom。成功的話，你會看到樹莓派的桌面，而且桌面上已經自動開了兩個終端機視窗。這兩個視窗很重要：一個是 agent，負責讓小腦連上大腦；一個是 Docker，裡面跑著 ROS 2。下一課會詳細介紹，這一課先不要關它們。

  1. VNC Viewer 上方位址列輸入 10.42.0.1 → Enter。
  2. 出現身分驗證提示 → Continue（繼續）。
  3. Username：pi，Password：yahboom → OK。
  4. 看到 Pi 5 桌面＝成功。

桌面上會有兩個開機自動啟動的終端機（官方影片 hq0Zbi7BmFA 第 2 分 10 秒起）：

終端機 在做什麼 怎麼看出正常
agent 終端機 啟動 micro-ROS agent，讓 ESP32 連進 ROS 2 輸出很多行訊息＝控制板已連上；只輸出兩行就停住＝還沒連上
Docker 終端機 進入裝好 ROS 2 Humble 的容器，並自動啟動手把控制 提示字元變成容器內的樣子
💡 小提示

沒接螢幕時 VNC 的畫面可能很小。可以在 Pi 5 終端機執行 sudo raspi-config → Display Options → VNC Resolution 調大解析度，存檔後重開機（官方 12 章 Pi 基本設定的內容）。

5. SSH：用文字終端機登入

🔊 旁白文字

接下來試試 SSH。在 Windows 打開 PowerShell，輸入 ssh 空格 pi 小老鼠 十點四十二點零點一。第一次連線會問你要不要信任這台主機，輸入 yes；接著輸入密碼 yahboom，畫面上不會顯示你打的字，這是正常的，打完按 Enter 就好。登入成功後，提示字元會變成 pi 小老鼠什麼什麼，代表你現在打的每一個指令，都是在車上的樹莓派執行，不是在你的電腦。

在 Windows
ssh pi@10.42.0.1
  • 第一次會問 Are you sure you want to continue connecting (yes/no...)? → 輸入 yes。
  • 密碼 yahboom（輸入時不顯示，正常）。

登入後試幾個指令，確認你真的在車上：

在 Pi 5 主機
hostname
hostname -I
ls ~
  • hostname：這台 Pi 的名字（之後改連家裡 WiFi 時有用，先記下來）。
  • hostname -I：目前所有 IP，熱點模式下會包含 10.42.0.1。
  • ls ~：家目錄裡應該看得到 start_agent_rpi5.sh、ros2_humble.sh、config_robot.py（下一課會用）。

從電腦傳檔到車上（或反過來）用 scp：

在 Windows
scp Test.txt pi@10.42.0.1:Desktop/
scp pi@10.42.0.1:Test.txt .

離開 SSH：

在 Pi 5 主機
exit
⚠️ 注意

官方 Linux 課程（第 11 章）的 SSH 範例寫成 sshpi@192.168.2.93，是排版吃掉空格，正確要有空格：ssh pi@IP。另外那幾篇用的帳號 jetson、IP 192.168.2.93 是 Jetson 產品的範例，本車帳號是 pi，熱點時 IP 是 10.42.0.1。

ℹ️ 補充

SSH 進去的終端機沒有圖形畫面，所以 rqt、rviz2 這類要開視窗的程式，請在 VNC 桌面的終端機裡執行。

6. 登入後的健康檢查與正確關機

🔊 旁白文字

第一次登入，我們順便幫車子做個健康檢查，就像新車交車時看一下儀表板。看看記憶卡還剩多少空間、記憶體夠不夠、處理器溫度多少，再確認控制板的序列線和攝影機這兩個 USB 裝置，都有被系統認到。最後學一個很重要的習慣：關車之前，先讓樹莓派正常關機，等綠燈不再閃了，才關擴展板的總開關。直接斷電就像拔掉電腦插頭，記憶卡裡的系統可能會壞掉，那就得重灌了。

SSH 登入後依序執行：

在 Pi 5 主機
df -h /
free -h
cat /sys/class/thermal/thermal_zone0/temp
ls /dev/ttyUSB*
ls /dev/video*
docker ps
docker images
指令 看什麼 正常狀況
df -h / microSD 卡剩餘空間 Avail 欄位至少還有幾 GB
free -h 記憶體用量 available 不要接近 0
cat /sys/class/thermal/thermal_zone0/temp CPU 溫度，數字除以 1000 是攝氏度 例如 52000 ＝ 52°C；長時間超過 80°C 要檢查散熱器風扇
ls /dev/ttyUSB* 擴展板 Serial 線 出現 /dev/ttyUSB0
ls /dev/video* USB 攝影機 出現 /dev/video0 等
docker ps 正在跑的容器 開機自動啟動時，會看到 agent 與 ROS 2 兩個容器
docker images 車上有哪些映像 應有 microros/micro-ros-agent 與 yahboomtechnology/ros-humble
ℹ️ 補充

docker 指令若出現 permission denied，代表目前使用者不在 docker 群組，前面加 sudo 再試；出廠系統的設定需實車確認。

正確關機（兩種擇一）：

在 Pi 5 主機
sudo shutdown -h now
在 Pi 5 主機
sudo reboot

shutdown -h now 是關機，reboot 是重開機。下了關機指令後，等 Pi 5 的綠色活動燈不再閃爍（約 10～20 秒），再關擴展板的電源開關。也可以在 VNC 桌面左上角選單選 Logout → Shutdown。

⚠️ 注意

直接關擴展板總開關等於「拔插頭」，microSD 卡寫到一半就斷電，可能讓系統開不了機。電量低警報響起時也一樣：先下關機指令，再關總開關、充電。

7. 改連家裡的 WiFi（選做，但很實用）

🔊 旁白文字

用熱點有一個缺點：電腦連著車就不能上網，查資料很不方便。解決方法是讓樹莓派改去連家裡的 WiFi，電腦也連家裡 WiFi，兩邊就在同一個網路，電腦還能上網。原理是「優先順序」。樹莓派裡存了好幾個網路設定，開機時會連優先數字最大的那一個。出廠熱點的優先數字是一，所以我們新增家裡 WiFi 時，把優先數字設成二以上，重開機它就會改連家裡 WiFi。

步驟（官方 03.Preparation/4，沒有螢幕、用 VNC 操作）：

  1. VNC 桌面右上角 WiFi 圖示 → Advanced Options → Edit Connections...
  2. 左下角 「+」 → 選 Wireless（WiFi）→ Create。
  3. 填寫： - SSID：家裡 WiFi 名稱。 - General 頁籤：勾選 Connect automatically with priority，數字設 ≥ 2（熱點是 1，WiFi 必須比熱點大）。 - Wi-Fi Security：選 WPA/WPA2/WPA3 Personal，輸入家裡 WiFi 密碼。
  4. Save 存檔。
  5. 重開 Pi 5，它會優先連家裡 WiFi。

改連之後怎麼找到車的 IP？ 熱點消失後 10.42.0.1 就不能用了，你需要車在家裡網路的新 IP：

方法 作法 備註
官方方法 在電腦的 ROS 2 環境執行 ros2 topic echo /rpi5_ip 電腦要和車在同一 WiFi、ROS_DOMAIN_ID 相同（預設 20）；同 WiFi 有多台車會看到多個 IP
路由器管理頁 登入家裡路由器，看已連線裝置清單 找名字等於剛才 hostname 的那台
主機名稱 ping <hostname>.local 樹莓派系統通常有 mDNS，可直接用名字連（需實車確認）
接網路線 Pi 5 用網路線接路由器 一樣到路由器查 IP

官方方法的指令（在電腦上執行；暖身課 W2 已在 WSL 裝好 Jazzy 的可以這樣做）：

在電腦 WSL（Jazzy）
export ROS_DOMAIN_ID=20
ros2 topic echo /rpi5_ip

找到 IP 之後，VNC 和 SSH 都改用新 IP，例如 ssh pi@192.168.1.50。

⚠️ 注意

官方原文寫「打開資料中提供的虛擬機」再執行 ros2 topic echo /rpi5_ip。官方虛擬機是 Humble；在 WSL 的 Jazzy 也可以收到這個話題，但 WSL 要設定 mirrored 網路才看得到區網裡的車（A5 單元會教）。/rpi5_ip 是由誰發布、訊息型別是什麼，官方文件沒寫（需實車確認）。

💡 小提示

改之前先在 SSH 裡執行 hostname 記下車的名字。家裡 WiFi 不在的地方（例如帶去教室），車子應該會退回熱點模式，用 Micro_ros 照舊連（依優先順序的原理推論，需實車確認）。

8. 出問題時怎麼辦

🔊 旁白文字

連線問題九成出在「不在同一個網路」或「打錯地址」。遇到問題時，先用 ping 確認網路通不通，再查帳號密碼，最後才去改設定。另外有一個 Windows 常見的錯誤：如果你重灌過系統或有兩台車共用同一個地址，SSH 會跳出一大段警告說主機金鑰變了，拒絕連線。這不是被駭，只要把舊的紀錄刪掉再連一次就好。

症狀 可能原因 解法
WiFi 清單找不到 Micro_ros Pi 5 還沒開完機；車子已改連家裡 WiFi 多等 30 秒；若之前改過 WiFi，到家裡網路找車的 IP
連上熱點後電腦不能上網 熱點本來就沒有對外網路 正常現象；要上網就改連家裡 WiFi（第 6 節）
VNC 一直轉圈、連不上 電腦沒連在車的熱點；IP 打錯 ipconfig 確認是 10.42.0.x；ping 10.42.0.1
VNC 密碼錯誤 帳號打成 jetson 或大小寫錯 帳號 pi、密碼 yahboom，全小寫
VNC 畫面很小 沒接螢幕時的預設解析度 sudo raspi-config → Display Options → VNC Resolution
ssh: connect to host ... Connection refused SSH 服務沒開 先用 VNC 進去，sudo raspi-config → Interface Options → SSH → Enable（官方 12 章）
ssh 出現 REMOTE HOST IDENTIFICATION HAS CHANGED 同一個 IP 之前連過別台或重灌過 在 Windows 執行 ssh-keygen -R 10.42.0.1 後重連
改連家裡 WiFi 後重開機仍是熱點 優先數字沒有大於 1；密碼打錯 重新 Edit Connections，priority 設 ≥ 2，確認密碼
找不到車在家裡網路的 IP 不在同一網路、路由器隔離 查路由器清單；或接網路線；最後手段是拔掉家裡 WiFi 設定退回熱點
開機後一直進不了桌面、VNC 連不上 之前直接斷電，microSD 卡系統損壞 先重開機一次；仍不行需重新燒錄系統映像（官方文件沒有提供 Pi 5 映像燒錄教學，需向賣家索取映像）；平常一定先 sudo shutdown -h now
指令打了沒反應或說找不到檔案 你其實還在 Windows，不在車上 看提示字元：pi@... 才是在車上
⚠️ 注意

官方 Linux 課程第 11-14 篇教你把軟體源換成 mirrors.aliyun.com/raspbian ... buster，那是舊版系統用的中國大陸鏡像，Pi 5 照抄會把系統弄壞。也不建議隨意 sudo apt full-upgrade，可能破壞出廠配好的環境。
