1. 我們要做什麼：感測、判斷、動作

🔊 旁白文字

前一單元你用的是官方寫好的避障程式，這一單元換你自己寫一個。目標刻意訂得很小：車子一直往前走，光達看到正前方三十公分內有東西就停下，東西移開了就繼續走。雖然簡單，但它包含了所有機器人程式的骨架：訂閱感測器、做判斷、發布動作指令。我們先在電腦上的模擬車測到沒問題，再搬到真車上，這樣撞到的只會是虛擬的牆。

/scan（sensor_msgs/LaserScan）──▶ obstacle_stop 節點 ──▶ /cmd_vel（geometry_msgs/Twist）
        光達一圈距離                 前方 ±15° 最近距離 < 0.3 m？           linear.x = 0.1 或 0

設計決定（每一條都是為了避免新手常見的事故）：

決定 為什麼
只看正前方 ±15° 側邊的牆不該讓車停下
過濾 inf、nan、0 與超出 range_min～range_max 的值 無效點不過濾，會被當成「超近的障礙」
用計時器固定 10 Hz 發速度，而不是收到 /scan 才發 速度指令穩定、好除錯
超過 0.5 秒沒收到 /scan 就停車 光達斷線時不能「瞎開」
停車後要退到 0.35 m 以外才再走（遲滯） 避免在 0.3 m 邊界上「走、停、走、停」抖動
速度、距離都做成參數 不用改程式就能用 ros2 param set 調整（M4 學過）
按 Ctrl+C 時先送零速度 程式結束不會讓車帶著最後的速度繼續衝
ℹ️ 補充

這一單元會用到 W2 的節點、話題、參數觀念，以及 M4 的 /scan 角度公式。忘了的話先回去看一眼「第 i 條雷射的角度 = angle_min + angle_increment × i」。

2. 建立工作空間與套件

🔊 旁白文字

ROS 2 的程式不是一個個散落的檔案，而是放在「套件」裡，套件再放在「工作空間」的 src 資料夾。工作空間就像一個專案資料夾，套件像專案裡的模組。我們用 ros2 pkg create 這個指令，一次產生套件需要的所有檔案骨架，包括 setup py 和 package xml，再把裡面的內容換成我們準備好的版本。我們另外開一個新的工作空間，不要和模擬車的工作空間混在一起。

在電腦 WSL（Jazzy）
source /opt/ros/jazzy/setup.bash
mkdir -p ~/my_ws/src
cd ~/my_ws/src
ros2 pkg create my_obstacle_stop --build-type ament_python \
  --dependencies rclpy sensor_msgs geometry_msgs --node-name obstacle_stop

產生出來的結構（--node-name 會自動幫你建好 obstacle_stop.py 並登記到 setup.py）：

~/my_ws/
└── src/
    └── my_obstacle_stop/
        ├── package.xml              ← 套件名稱、依賴
        ├── setup.py                 ← 怎麼安裝、有哪些可執行檔（entry_points）
        ├── setup.cfg                ← 可執行檔安裝到哪裡
        ├── resource/my_obstacle_stop   ← 空檔案，讓 ROS 找得到這個套件
        ├── test/                    ← 自動產生的程式風格測試（可先不管）
        └── my_obstacle_stop/
            ├── __init__.py
            └── obstacle_stop.py     ← 我們要寫的節點

接下來三個小節，請用編輯器把檔案內容整個換掉。在 WSL 可用 nano 檔名（貼上後 Ctrl+O 存檔、Ctrl+X 離開），或在 Windows 用 VS Code 開 \\wsl$\Ubuntu-24.04\home\<你的帳號>\my_ws。

3. 節點程式 obstacle_stop.py

🔊 旁白文字

這支程式分成三塊。第一塊是建構時宣告參數、建立訂閱者和發布者，還有一個每零點一秒觸發一次的計時器。第二塊是光達的回呼函式，每收到一圈資料，就挑出正前方扇形裡最近的距離存起來。第三塊是計時器的回呼函式，拿最近距離和停車距離比較，決定要送前進速度還是零速度。收資料和做決定分開，是寫控制程式很重要的習慣。

在電腦 WSL（Jazzy）（~/my_ws/src/my_obstacle_stop/my_obstacle_stop/obstacle_stop.py）
"""前方有障礙就停車、沒有就前進的第一個控制節點。

訂閱 /scan（sensor_msgs/LaserScan），發布 /cmd_vel（geometry_msgs/Twist）。
"""
import math

import rclpy
from rclpy.executors import ExternalShutdownException
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan


class ObstacleStop(Node):
    def __init__(self):
        super().__init__('obstacle_stop')

        # 參數：執行中可用 ros2 param set 修改，每次計時器觸發都重新讀取
        self.declare_parameter('stop_distance', 0.3)     # 公尺，比這近就停
        self.declare_parameter('resume_margin', 0.05)    # 公尺，要退到 stop_distance + 這個值才再走
        self.declare_parameter('forward_speed', 0.1)     # 公尺/秒，前進速度
        self.declare_parameter('front_angle_deg', 15.0)  # 度，只看正前方左右各幾度
        self.declare_parameter('angle_offset_deg', 0.0)  # 度，光達裝歪或零度不在正前方時用來修正
        self.declare_parameter('scan_timeout', 0.5)      # 秒，超過這麼久沒收到 /scan 就停車

        # 光達資料常用「盡力傳送」QoS，用 sensor_data 設定才收得到兩種發布者
        self.sub_scan = self.create_subscription(
            LaserScan, '/scan', self.scan_callback, qos_profile_sensor_data)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)

        self.front_min = math.inf        # 前方扇形內最近距離
        self.last_scan_time = None       # 最後一次收到 /scan 的時間
        self.blocked = False             # 目前是否判定「被擋住」
        self.timer = self.create_timer(0.1, self.control_loop)  # 10 Hz 送速度
        self.get_logger().info('obstacle_stop 已啟動，等待 /scan ...')

    def scan_callback(self, msg):
        """從一整圈資料中，找出正前方扇形內的最近距離。"""
        front_angle = math.radians(self.get_parameter('front_angle_deg').value)
        offset = math.radians(self.get_parameter('angle_offset_deg').value)
        nearest = math.inf
        for i, distance in enumerate(msg.ranges):
            # 無效值：inf、nan、0，或超出光達量測範圍，一律跳過
            if not math.isfinite(distance) or distance <= 0.0:
                continue
            if distance < msg.range_min or distance > msg.range_max:
                continue
            angle = msg.angle_min + msg.angle_increment * i - offset
            # 角度壓到 -pi ~ +pi，0 代表正前方、正值在左邊
            angle = math.atan2(math.sin(angle), math.cos(angle))
            if abs(angle) <= front_angle and distance < nearest:
                nearest = distance
        self.front_min = nearest
        self.last_scan_time = self.get_clock().now()

    def control_loop(self):
        """每 0.1 秒決定一次要停還是要走。"""
        stop_distance = self.get_parameter('stop_distance').value
        resume_margin = self.get_parameter('resume_margin').value
        forward_speed = self.get_parameter('forward_speed').value
        scan_timeout = self.get_parameter('scan_timeout').value

        cmd = Twist()
        if self.last_scan_time is None:
            self.pub_vel.publish(cmd)  # 還沒收到光達：原地不動
            return
        age = (self.get_clock().now() - self.last_scan_time).nanoseconds / 1e9
        if age > scan_timeout:
            self.get_logger().warn('超過 %.1f 秒沒收到 /scan，先停車' % age,
                                   throttle_duration_sec=2.0)
            self.pub_vel.publish(cmd)
            return

        # 遲滯：停下來之後，要離開到更遠一點才重新出發，避免在邊界抖動
        if self.blocked:
            if self.front_min > stop_distance + resume_margin:
                self.blocked = False
                self.get_logger().info('前方淨空 %.2f m，繼續前進' % self.front_min)
        elif self.front_min < stop_distance:
            self.blocked = True
            self.get_logger().info('前方 %.2f m 有障礙，停車' % self.front_min)

        if not self.blocked:
            cmd.linear.x = float(forward_speed)
        self.pub_vel.publish(cmd)

    def stop_robot(self):
        """結束前送一個零速度，讓車停下來。"""
        self.pub_vel.publish(Twist())


def init_ros(args):
    """關掉 rclpy 自帶的 Ctrl+C 處理，按 Ctrl+C 時才來得及送出停車指令。"""
    try:
        from rclpy.signals import SignalHandlerOptions
        rclpy.init(args=args, signal_handler_options=SignalHandlerOptions.NO)
    except ImportError:
        rclpy.init(args=args)


def main(args=None):
    init_ros(args)
    node = ObstacleStop()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        if rclpy.ok():
            node.stop_robot()
        node.destroy_node()
        if rclpy.ok():
            rclpy.shutdown()


if __name__ == '__main__':
    main()

逐段重點：

  • qos_profile_sensor_data：QoS（Quality of Service，服務品質）決定訊息「一定要送到」還是「盡力就好」。感測器資料常用「盡力傳送」（best effort），訂閱端若要求「一定送到」（reliable）會配對失敗、一筆都收不到。訂閱端設成 sensor_data（盡力），對兩種發布者都收得到。
  • 角度換算：angle_min + angle_increment * i 後用 atan2(sin, cos) 壓到 -π～+π，不管光達的 angle_min 是 0 還是 -π 都適用。
  • angle_offset_deg：如果實車光達的 0° 不是正前方（例如裝反了 180°），改這個參數就好，不用改程式。
  • 遲滯：blocked 這個布林值記住「我現在是停著的」，要大於 stop_distance + resume_margin 才放行。
  • init_ros()：把 rclpy 內建的 Ctrl+C 處理關掉，讓 KeyboardInterrupt 正常拋出，finally 裡才來得及送零速度；try/except ImportError 讓同一份程式在 Humble 與 Jazzy 都能跑。

4. setup.py、package.xml、setup.cfg

🔊 旁白文字

程式寫好了，還要告訴 ROS 兩件事：這個套件依賴哪些其他套件，以及要把哪個 Python 函式變成可以 ros2 run 的指令。前者寫在 package xml，後者寫在 setup py 的 entry points。entry points 裡那一行的意思是：指令名稱叫 obstacle stop，執行的是套件裡 obstacle stop 這個檔案的 main 函式。指令名稱打錯一個字，ros2 run 就會說找不到可執行檔。

在電腦 WSL（Jazzy）（~/my_ws/src/my_obstacle_stop/setup.py）
from setuptools import find_packages, setup

package_name = 'my_obstacle_stop'

setup(
    name=package_name,
    version='0.1.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='student',
    maintainer_email='student@example.com',
    description='My first ROS 2 node: stop when an obstacle is within 0.3 m.',
    license='Apache-2.0',
    entry_points={
        'console_scripts': [
            'obstacle_stop = my_obstacle_stop.obstacle_stop:main',
        ],
    },
)
在電腦 WSL（Jazzy）（~/my_ws/src/my_obstacle_stop/package.xml）
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>my_obstacle_stop</name>
  <version>0.1.0</version>
  <description>My first ROS 2 node: stop when an obstacle is within 0.3 m.</description>
  <maintainer email="student@example.com">student</maintainer>
  <license>Apache-2.0</license>

  <exec_depend>rclpy</exec_depend>
  <exec_depend>sensor_msgs</exec_depend>
  <exec_depend>geometry_msgs</exec_depend>

  <export>
    <build_type>ament_python</build_type>
  </export>
</package>
在電腦 WSL（Jazzy）（~/my_ws/src/my_obstacle_stop/setup.cfg，自動產生的通常已經一樣）
[develop]
script_dir=$base/lib/my_obstacle_stop
[install]
install_scripts=$base/lib/my_obstacle_stop
對應關係 必須一致的地方
套件名 my_obstacle_stop package.xml 的 <name>、setup.py 的 package_name、resource/ 底下的空檔名、內層資料夾名、setup.cfg 路徑
指令名 obstacle_stop entry_points 等號左邊；ros2 run my_obstacle_stop obstacle_stop 的第二個字
模組路徑 my_obstacle_stop.obstacle_stop:main 內層資料夾 / 檔名 / def main
💡 小提示

這份 setup.py 拿掉了自動產生版本中的 tests_require，避免 Jazzy 較新的 setuptools 一直印棄用警告。測試資料夾 test/ 留著沒關係，colcon build 不會執行它。

5. 編譯與在模擬車上測試

🔊 旁白文字

現在開四個終端。第一個開模擬車，第二個編譯並執行你的節點，第三個觀察速度話題，第四個用來即時改參數。編譯用 colcon build，編譯完一定要 source 一次 install 底下的 setup bash，這個終端才認得你的新套件。每次改了程式都要重新編譯，除非你用 symlink install 的方式編譯。看到模擬車往前走、在牆前停下，就成功了一半。

終端 1：模擬車（模擬環境由講義另外提供，會發布 /scan、/odom、/imu、/tf，接收 /cmd_vel）：

在電腦 WSL（Jazzy）
cd ~/yahboom_ws && source install/setup.bash && ros2 launch microros_pi5_sim sim.launch.xml

終端 2：編譯並執行：

在電腦 WSL（Jazzy）
source /opt/ros/jazzy/setup.bash
cd ~/my_ws
colcon build --symlink-install --packages-select my_obstacle_stop
source install/setup.bash
ros2 run my_obstacle_stop obstacle_stop

--symlink-install 讓 Python 檔用「捷徑」安裝，之後只改 .py 不用重新編譯（改 setup.py 或新增檔案仍要重編）。

終端 3：觀察：

在電腦 WSL（Jazzy）

終端 4：即時調參數：

在電腦 WSL（Jazzy）

# 也可以啟動時直接帶參數：

驗收（模擬車）：

  1. 終端 2 先印 obstacle_stop 已啟動，等待 /scan ...。
  2. 車往前走；靠近牆時印 前方 0.29 m 有障礙，停車，/cmd_vel 變成 0。
  3. 在模擬器裡把車拖開或轉個方向，印 前方淨空 ... m，繼續前進。
  4. 終端 2 按 Ctrl+C，車立刻停下、沒有錯誤訊息。
  5. 關掉終端 1 的模擬車，約 0.5 秒後終端 2 印 超過 ... 秒沒收到 /scan，先停車。

6. 搬到實車：在 Docker 容器內編譯執行

🔊 旁白文字

程式在模擬車上沒問題，就可以搬到真車。要注意車上的 ROS 是裝在 Docker 容器裡的 Humble，而容器是「暫時的」，關掉後在裡面建的檔案可能就不見了。所以我們把原始碼放在 Pi 5 主機上，再複製進容器編譯；編譯好之後，可以用 docker commit 把容器存成新的映像。第一次在實車上跑，一定要把車架高讓輪子懸空，用手在光達前面晃，確認會停再放到地上。

步驟 1：把套件從電腦複製到 Pi 5 主機（車子 IP 以熱點模式 10.42.0.1 為例）：

在電腦 WSL（Jazzy）
cd ~/my_ws/src
tar czf my_obstacle_stop.tgz --exclude=__pycache__ my_obstacle_stop
scp my_obstacle_stop.tgz pi@10.42.0.1:~/        # 密碼 yahboom

步驟 2：在 Pi 5 主機解開，再複製進容器：

在 Pi 5 主機
mkdir -p ~/my_ws/src && tar xzf ~/my_obstacle_stop.tgz -C ~/my_ws/src
sh ~/start_agent_rpi5.sh                         # 終端 A：agent，按控制板 reset
sh ros2_humble.sh                                # 終端 B：進容器
# 終端 C（主機）：找到容器 ID，把工作空間複製進去
docker ps -a
docker cp ~/my_ws ef0e1b7da319:/root/            # ef0e1b7da319 換成你看到的 ID

步驟 3：在容器內編譯並執行（Humble 與 Jazzy 的指令完全一樣）：

在車上 Docker 容器內
cd /root/my_ws
colcon build --packages-select my_obstacle_stop
source install/setup.bash
ros2 topic hz /scan                              # 先確認有光達資料
ros2 run my_obstacle_stop obstacle_stop

步驟 4：架高測試 → 落地測試：

  1. 車架高，用手或紙板放在光達正前方 20 公分，應印 前方 0.2x m 有障礙，停車，輪子停。
  2. 若手放在車後方才停，代表光達 0° 不在正前方：Ctrl+C 後改用 ros2 run my_obstacle_stop obstacle_stop --ros-args -p angle_offset_deg:=180.0 再試（需實車確認 MS200 的安裝方向）。
  3. 放到空曠地面，速度維持 0.1 m/s，前方放紙箱，確認在約 30 公分處停下。

步驟 5（選做）：保存容器：

在 Pi 5 主機
docker commit -m="add my_obstacle_stop" ef0e1b7da319 my_humble:with_obstacle_stop
docker images
⚠️ 注意
  • 不要在第二個終端再跑一次 sh ros2_humble.sh，那會開出另一個新容器，裡面沒有你剛複製的 /root/my_ws。多開終端一律 docker exec -it <ID> /bin/bash。
  • docker commit 之後，要讓 ros2_humble.sh 改用新映像，得編輯腳本裡的映像名稱（腳本內容需實車 cat ~/ros2_humble.sh 確認）。不想改腳本的話，每次重新 docker cp 也可以。
  • 官方第 6 課範例把 while rclpy.ok() 迴圈寫在節點建構式裡，那樣 rclpy.spin() 永遠執行不到、回呼函式也不會被呼叫。控制程式請照本單元用 create_timer。

7. 出問題時怎麼辦

🔊 旁白文字

自己寫的第一個節點，出問題是正常的。大部分錯誤都落在四類：找不到套件或可執行檔、收不到光達資料、收到了但判斷不對、還有參數型別打錯。先看終端機印了什麼，再用 node list、topic info、topic echo 三個指令一路往下查，很快就能找到是哪一段沒接上。

症狀 原因 怎麼做
Package 'my_obstacle_stop' not found 沒在這個終端 source install/setup.bash，或編譯失敗 cd ~/my_ws && colcon build ... && source install/setup.bash
No executable found entry_points 指令名或模組路徑打錯；setup.cfg 路徑不對 對照第 4 小節的對應表；刪掉 build/ install/ log/ 重編
一直印「等待 /scan」，車不動 沒有光達資料、QoS 不相容、Domain ID 不同 ros2 topic hz /scan；ros2 topic info /scan -v 看 QoS；echo $ROS_DOMAIN_ID 兩邊一致
一直印「超過 … 秒沒收到 /scan」 光達頻率太低或斷線 先查 ros2 topic hz /scan；必要時 ros2 param set /obstacle_stop scan_timeout 1.0
前方明明沒東西也停 車身零件或線材被掃到、光達方向偏 把 front_angle_deg 調小（如 10.0）；確認 angle_offset_deg
在 0.3 m 附近一直走走停停 遲滯太小 ros2 param set /obstacle_stop resume_margin 0.1
ros2 param set 回 Setting parameter failed 型別不符，浮點數參數給了整數 寫 0.5、1.0，不要寫 1
模擬車不動但 /cmd_vel 有值 模擬沒在跑或被暫停 確認終端 1 的模擬器在執行（Gazebo 左下角播放鍵）
colcon build 出現 SetuptoolsDeprecationWarning Jazzy 較新的 setuptools 警告可忽略，只要最後是 Finished
Ctrl+C 後車還在動 程式異常結束沒送出零速度 ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{}"

進階挑戰：

  1. 把「停車」改成「原地左轉直到前方淨空」，就做出了自己的簡易避障。
  2. 加一個發布者，太近時對 /beep（std_msgs/UInt16，data: 1）叫一聲（只有實車有蜂鳴器）。
  3. 寫一個 launch 檔，一次啟動節點並帶入參數 YAML。
