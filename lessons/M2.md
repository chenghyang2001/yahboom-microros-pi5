## 1. MediaPipe 是什麼：一張影像進去，一串關鍵點出來

> 🔊 MediaPipe 是 Google 開源的機器學習工具組，裡面已經訓練好手、身體、臉的模型，
> 連樹莓派這種小電腦都跑得動。用法非常單純：你把一張 RGB 影像交給它，它回給你一串「關鍵點」，
> 每個點有 x、y 座標，數值是零到一之間的比例，乘上影像寬高才是像素位置。
> 你不用懂神經網路，只要會讀這串點，就能判斷手指有沒有伸直、人站在畫面哪裡。

| 模型 | 官方程式 | 關鍵點數 | 用途 |
| --- | --- | --- | --- |
| Hands 手部 | `01_HandDetector` | **21 點**／每隻手 | 手勢、手指控制 |
| Pose 姿態 | `02_PoseDetector` | **33 點** | 全身骨架 |
| Holistic 整體 | `03_Holistic` | 臉＋身體＋雙手 | 一次全抓，最吃運算 |
| FaceMesh 臉部網格 | `04_FaceMesh` | 468 點 | 臉部輪廓 |
| Haar 級聯（不是 MediaPipe） | `05_FaceEyeDetection` | 臉框、眼框 | 老派但快的「偵測」 |

共同的三步驟：

```python title="在 Windows（概念示意）"
img_RGB = cv.cvtColor(frame, cv.COLOR_BGR2RGB)   # 1. OpenCV 是 BGR，MediaPipe 要 RGB
results = hands.process(img_RGB)                 # 2. 丟進模型
for lm in results.multi_hand_landmarks[0].landmark:
    cx, cy = int(lm.x * w), int(lm.y * h)        # 3. 0~1 比例 → 像素座標
```

:::info
「偵測（detection）」和「辨認（recognition）」不一樣：偵測只回答「畫面裡有沒有臉、在哪裡」，辨認才回答「這是誰」。官方 7.5 叫 Face recognition，實際做的是偵測。
:::

## 2. 手部 21 個關鍵點與「手指伸直」的判斷規則

> 🔊 手部模型會給你二十一個點：零號是手腕，每根手指各有四個點，從指根一路編到指尖。
> 五根手指的指尖分別是四、八、十二、十六、二十號。判斷手指有沒有伸直，官方用的是很樸素的規則：
> 食指到小指，只要指尖比往下數第二個關節更高，就算伸直；拇指是橫著動的，
> 所以改看三個關節排起來是不是接近一直線。之後所有手勢都是用這五個零或一組合出來的。

```
          8   12  16  20      ← 指尖 TIP
          7   11  15  19      ← DIP
    4     6   10  14  18      ← PIP（指尖編號 - 2）
    3     5    9  13  17      ← MCP 指根（9 = 中指根，M3 拿它當「手掌中心」）
     2
      1
         0  ← 手腕 WRIST
```

| 手指 | 編號 | 伸直的判斷 |
| --- | --- | --- |
| 拇指 | 1、2、3、4 | 4-3-2 與 3-2-1 兩個夾角都 **> 150°**（接近一直線） |
| 食指 | 5、6、7、8 | 指尖 8 的 y **小於** 6 的 y（影像 y 往下變大，所以「小」= 比較高） |
| 中指 | 9～12 | 12 的 y < 10 的 y |
| 無名指 | 13～16 | 16 的 y < 14 的 y |
| 小指 | 17～20 | 20 的 y < 18 的 y |

結果是一個串列，例如 `[0, 1, 1, 0, 0]` 代表食指和中指伸直，也就是手勢「2」。

**規則式手勢**（官方 `11_GestureRecognition.py` 的 `get_gesture()`，共 14 種：`Zero, One, Two, Three, Four, Five, Six, Seven, Eight, Ok, Rock, Thumb_up, Thumb_down, Heart_single`）：

| 伸直根數 | 判斷 | 手勢 |
| --- | --- | --- |
| 0 | — | Zero |
| 1 | — | One |
| 2 | 拇指＋小指 | Six |
| 2 | 拇指＋食指且夾角 > 90° | Eight |
| 2 | 拇指、食指指尖距離 < 50 像素 | Heart_single |
| 2 | 其他 | Two |
| 3～4 | 拇指伸直且拇指尖到食指尖比到食指根近 | OK |
| 3～4 | 中指、無名指都彎 | Rock |
| 5 | — | Five |
| — | 拇指尖比其他四指尖都低／都高 | Thumb_down／Thumb_up |
| — | 拇指尖到其他四指尖都 < 60 像素 | Seven |

:::tip
這是「規則」不是「學習」，所以手轉個角度、離鏡頭太遠（距離門檻是像素）、或手背對鏡頭都會誤判。官方也說這套規則是照**右手**設計的。比手勢時手心朝鏡頭、手指朝上最穩。
:::

## 3. 在筆電上安裝 MediaPipe（注意 Python 版本）

> 🔊 這裡有一個很容易卡住的版本問題。車上容器裡的程式用的是 MediaPipe 舊版的寫法，
> 叫做 solutions。可是最新版的 MediaPipe 已經把這套舊寫法拿掉了，
> 而且最新版的 Python 也只能裝到新版。所以筆電練習要刻意裝一個 Python 三點一二，
> 再在獨立的虛擬環境裡裝指定版本的 MediaPipe，這樣你寫的程式才會和車上的寫法一樣。

```bash title="在 Windows（Git Bash）"
# 1. 裝 Python 3.12（已經有的話跳過；py -0 可列出已安裝的版本）
winget install -e --id Python.Python.3.12
py -0
# 2. 建一個專門給 MediaPipe 用的虛擬環境，並安裝指定版本
py -3.12 -m venv ~/mp-venv
~/mp-venv/Scripts/python -m pip install mediapipe==0.10.21 opencv-python
# 3. 確認舊版 solutions 寫法可用，印出 True 才算成功
~/mp-venv/Scripts/python -c "import mediapipe as mp; print(mp.__version__, hasattr(mp, 'solutions'))"
```

:::warn

- 2026 年實測：在 Python 3.14 上 `pip install mediapipe` 只能裝到 0.10.30 以後的版本，這些版本**已經沒有 `mp.solutions`**，官方範例會直接噴 `AttributeError: module 'mediapipe' has no attribute 'solutions'`。一定要用 Python 3.12 ＋ `mediapipe==0.10.21`。
- 不要裝在 WSL 裡練這一課：筆電鏡頭要轉進 WSL 很麻煩（要另外設定 usbipd），Windows 原生最省事。

:::

## 4. 動手：21 點＋手勢＋「如果是車會怎麼動」

> 🔊 這支練習程式把官方兩支程式濃縮在一起：前半段是手勢辨識，後半段是第三單元手勢控車的對應表。
> 畫面會標出二十一個點的編號、五根手指的伸直狀態、判斷出來的手勢，
> 以及如果這是車子，它會送出什麼樣的速度指令。先別急著上車，
> 在筆電把每個手勢都比到穩定為止，上車後就只剩下車子本身的問題。

把下面存成 `hand_gesture.py`，用 `~/mp-venv/Scripts/python hand_gesture.py` 執行：

```python title="在 Windows（hand_gesture.py）"
"""筆電 webcam：MediaPipe 21 點手部偵測 + 規則式手勢判斷（仿官方 11_GestureRecognition 與 HandCtrl）。按 q 離開。"""
import math
import sys
import time
import cv2 as cv
import mediapipe as mp

TIP_IDS = [4, 8, 12, 16, 20]   # 拇指、食指、中指、無名指、小指的指尖編號


def get_dist(p1, p2):
    return math.hypot(p1[0] - p2[0], p1[1] - p2[1])


def calc_angle(p1, p2, p3):
    """以 p2 為頂點的夾角（度），用餘弦定理。"""
    a, b, c = get_dist(p1, p2), get_dist(p2, p3), get_dist(p1, p3)
    try:
        return math.degrees(math.acos((a * a + b * b - c * c) / (2 * a * b)))
    except (ValueError, ZeroDivisionError):
        return 0.0


def fingers_up(lm):
    """回傳五個 0/1：[拇指, 食指, 中指, 無名指, 小指]，1 代表伸直。"""
    fingers = []
    # 拇指：4-3-2 與 3-2-1 兩個夾角都接近一直線（> 150 度）才算伸直
    thumb_straight = calc_angle(lm[4], lm[3], lm[2]) > 150 and calc_angle(lm[3], lm[2], lm[1]) > 150
    fingers.append(1 if thumb_straight else 0)
    # 其他四指：指尖比 PIP 關節（指尖編號 - 2）更「上面」就算伸直；畫面 y 往下變大
    for tip in TIP_IDS[1:]:
        fingers.append(1 if lm[tip][1] < lm[tip - 2][1] else 0)
    return fingers


def get_gesture(lm, fingers):
    """官方規則的精簡版：只判斷幾種最穩定的手勢。"""
    n = sum(fingers)
    if n == 0:
        return "Zero"
    if n == 5:
        return "Five"
    if n == 1 and fingers[1] == 1:
        return "One"
    if n == 2 and fingers[1] == fingers[2] == 1:
        return "Two"
    if n == 2 and fingers[0] == fingers[4] == 1:
        return "Six"
    if n in (3, 4) and fingers[0] == 1 and get_dist(lm[4], lm[8]) < get_dist(lm[4], lm[5]):
        return "OK"
    return "?"


# 官方 HandCtrl 的對應：手勢 → (linear.x, angular.z)
HANDCTRL_TABLE = {"Five": (0.3, 0.0), "Zero": (-0.3, 0.0), "One": (0.0, 0.5), "Two": (0.0, -0.5)}


def main():
    cap = cv.VideoCapture(0)
    if not cap.isOpened():
        sys.exit("錯誤：打不開鏡頭，請關掉其他占用鏡頭的程式")
    cap.set(cv.CAP_PROP_FRAME_WIDTH, 640)
    cap.set(cv.CAP_PROP_FRAME_HEIGHT, 480)
    hands = mp.solutions.hands.Hands(max_num_hands=1, min_detection_confidence=0.75,
                                     min_tracking_confidence=0.5)
    draw = mp.solutions.drawing_utils
    p_time = time.time()
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        frame = cv.flip(frame, 1)                      # 鏡像，像照鏡子比較好操作
        h, w = frame.shape[:2]
        results = hands.process(cv.cvtColor(frame, cv.COLOR_BGR2RGB))   # MediaPipe 要 RGB
        if results.multi_hand_landmarks:
            hand = results.multi_hand_landmarks[0]
            draw.draw_landmarks(frame, hand, mp.solutions.hands.HAND_CONNECTIONS)
            lm = [(int(p.x * w), int(p.y * h)) for p in hand.landmark]   # 0~1 比例 → 像素
            for i, (x, y) in enumerate(lm):
                cv.putText(frame, str(i), (x + 4, y - 4), cv.FONT_HERSHEY_PLAIN, 0.9, (255, 255, 0), 1)
            fingers = fingers_up(lm)
            gesture = get_gesture(lm, fingers)
            vel = HANDCTRL_TABLE.get(gesture, (0.0, 0.0))
            cv.rectangle(frame, (0, 400), (640, 480), (0, 0, 0), cv.FILLED)
            cv.putText(frame, f"{fingers} {gesture}", (10, 430), cv.FONT_HERSHEY_SIMPLEX, 0.9, (0, 255, 0), 2)
            cv.putText(frame, f"cmd_vel: x={vel[0]} z={vel[1]}", (10, 470), cv.FONT_HERSHEY_SIMPLEX, 0.8, (0, 200, 255), 2)
        c_time = time.time()
        cv.putText(frame, f"FPS: {int(1 / max(c_time - p_time, 1e-6))}", (10, 30),
                   cv.FONT_HERSHEY_SIMPLEX, 0.8, (0, 0, 255), 2)
        p_time = c_time
        cv.imshow('hand', frame)
        if cv.waitKey(1) & 0xFF == ord('q'):
            break
    cap.release()
    cv.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**練習清單**：

1. 比 5、拳頭、1、2，看下方是否顯示 `Five`、`Zero`、`One`、`Two`，以及 `cmd_vel` 的數值（這就是 M3 `HandCtrl` 的前進、後退、左轉、右轉）。
2. 把手慢慢轉成側面，觀察 `fingers` 什麼時候開始判斷錯——這就是規則式方法的極限。
3. 進階：仿照 7.9 Finger control，用 `calc_angle(lm[4], lm[0], lm[8])`（拇指尖、手腕、食指尖的夾角）配 `np.interp(angle, [0, 70], [0, 255])` 做一個「手指滑桿」。M3 控車速也是同樣的線性映射觀念。

## 5. 姿態 33 點與臉部網格

> 🔊 手部以外，姿態模型會給你全身三十三個點，零號是鼻子，肩膀、手肘、膝蓋都有編號；
> 臉部網格則有四百六十八個點，能描出整張臉的輪廓。這兩個模型的用法和手部一模一樣，
> 只是換一個模型名稱、換一種畫線方式。下面這支小程式按 f 就能在兩者之間切換，
> 你可以觀察鼻子座標怎麼隨你左右移動而變化，這就是「追人」的基礎。

```python title="在 Windows（pose_face.py）"
"""筆電 webcam：按 f 在 姿態 33 點 / 臉部網格 468 點 之間切換，按 q 離開。"""
import sys
import cv2 as cv
import mediapipe as mp

mp_pose, mp_face, draw = mp.solutions.pose, mp.solutions.face_mesh, mp.solutions.drawing_utils


def main():
    cap = cv.VideoCapture(0)
    if not cap.isOpened():
        sys.exit("錯誤：打不開鏡頭")
    pose = mp_pose.Pose(min_detection_confidence=0.5, min_tracking_confidence=0.5)
    face = mp_face.FaceMesh(max_num_faces=1, min_detection_confidence=0.5)
    mode = "pose"
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        rgb = cv.cvtColor(frame, cv.COLOR_BGR2RGB)
        if mode == "pose":
            res = pose.process(rgb)
            if res.pose_landmarks:
                draw.draw_landmarks(frame, res.pose_landmarks, mp_pose.POSE_CONNECTIONS)
                nose = res.pose_landmarks.landmark[0]          # 0 號點是鼻子
                cv.putText(frame, f"nose x={nose.x:.2f} y={nose.y:.2f}", (10, 60),
                           cv.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)
        else:
            res = face.process(rgb)
            if res.multi_face_landmarks:
                for lms in res.multi_face_landmarks:
                    draw.draw_landmarks(frame, lms, mp_face.FACEMESH_CONTOURS)
        cv.putText(frame, f"mode: {mode} (f=switch, q=quit)", (10, 30),
                   cv.FONT_HERSHEY_SIMPLEX, 0.8, (0, 0, 255), 2)
        cv.imshow('pose_face', frame)
        key = cv.waitKey(1) & 0xFF
        if key == ord('q'):
            break
        if key == ord('f'):
            mode = "face" if mode == "pose" else "pose"
    cap.release()
    cv.destroyAllWindows()


if __name__ == "__main__":
    main()
```

## 6. 車上的官方程式：ros2 run 與 python3 兩種跑法

> 🔊 回到車上，官方的 MediaPipe 程式分成兩類。前五支是正式登記在套件裡的 ROS 節點，
> 用 ros2 run 啟動，會把關鍵點發布到 mediapipe points 話題；後面幾支只是普通 Python 腳本，
> 要先切換到程式所在的資料夾，再用 python3 直接執行。另外要注意，文件的課號和檔名編號對不起來，
> 照著下面的對照表找檔案就不會迷路。

**ROS 節點（會發布 `/mediapipe/points`，型別 `yahboomcar_msgs/PointArray`，內容是 `geometry_msgs/Point[] points`，座標為 0～1 比例）**：

```bash title="在車上 Docker 容器內"
ros2 run yahboomcar_mediapipe 01_HandDetector       # 7.1 手部 21 點
ros2 run yahboomcar_mediapipe 02_PoseDetector       # 7.2 姿態 33 點
ros2 run yahboomcar_mediapipe 03_Holistic           # 7.3 整體（Pi 5 上 FPS 最低）
ros2 run yahboomcar_mediapipe 04_FaceMesh           # 7.4 臉部網格
ros2 run yahboomcar_mediapipe 05_FaceEyeDetection   # 7.5 Haar 臉與眼；f 切換 face/eye/face_eye，發布 /FaceEyeDetection/image
# 另一個終端觀察：
ros2 topic echo /mediapipe/points
```

**直接執行的腳本**（一定要先 `cd`，因為 7.6 用相對路徑 `./file/shape_predictor_68_face_landmarks.dat` 讀 dlib 模型）：

```bash title="在車上 Docker 容器內"
cd ~/yahboomcar_ws/src/yahboomcar_mediapipe/yahboomcar_mediapipe
python3 06_FaceLandmarks.py       # 7.6 臉部特效（dlib 68 點）
python3 08_Objectron.py           # 7.7 3D 物體：f 切換 Shoe/Chair/Cup/Camera
python3 09_VirtualPaint.py        # 7.8 空中畫筆
python3 10_HandCtrl.py            # 7.9 手指控制特效：f 切換 color/thresh/blur/hue/enhance
python3 11_GestureRecognition.py  # 7.10 手勢辨識
```

| PDF 課號 | 實際檔名 |
| --- | --- |
| 7.6 Face effects | `06_FaceLandmarks.py` |
| 7.7 3D object recognition | `08_Objectron.py`（**沒有 07 這個課號的檔**；`07_FaceDetection.py` 是另一支） |
| 7.8 Brush | `09_VirtualPaint.py` |
| 7.9 Finger control | `10_HandCtrl.py` |
| 7.10 Gesture recognition | `11_GestureRecognition.py` |

:::warn

- PDF 貼的 7.1 範例是 `import rospy`、`rospy.Publisher`（ROS 1 寫法）配 `ros2 run`，前後矛盾。車上原始碼實際是 `rclpy`（ROS 2），**以車上檔案為準**，不要照 PDF 抄。
- PDF 寫 7.1、7.9 用 `VideoCapture(4)`；原始碼全部是 `VideoCapture(0)`。若畫面全黑，主機上 `ls /dev/video*` 確認編號。
- 7.5 的 PDF 程式碼有 `rospkg.RosPack().get_path("dofbot_mediapipe")`，是從機械手臂 dofbot 課程複製來的 ROS 1 殘留。
- 7.7 切換物件時要下載模型，**Pi 5 必須能上網**；熱點模式下沒有網路會卡住。
- 7.8 的文字把手指寫成「right and middle fingers」「middle and middle fingers」，正確規則是：食指＋中指伸直＝選色模式、只有食指＝畫畫模式。
- 套件裡的 `mediapipe_points.launch.py` 引用了不存在的 `yahboomcar_point` 套件與 `/home/nx-ros2/...` 路徑（從其他產品複製），不要用它。

:::

## 7. 出問題時怎麼辦

> 🔊 MediaPipe 的問題大多出在安裝版本和執行環境，不太會是你的程式邏輯。
> 如果一跑就說找不到 solutions，幾乎都是 MediaPipe 版本太新；如果畫面很卡，
> 先降低解析度或換成比較輕的模型。手勢判斷不穩的時候，先確認手心朝鏡頭、光線充足、
> 背景不要太花，再回頭看規則本身。

| 症狀 | 可能原因 | 怎麼做 |
| --- | --- | --- |
| `AttributeError: module 'mediapipe' has no attribute 'solutions'` | MediaPipe 太新（0.10.30 起移除舊 API） | 用第 3 小節的 Python 3.12 虛擬環境＋`mediapipe==0.10.21` |
| `pip install mediapipe==0.10.21` 說找不到版本 | 用到 Python 3.13／3.14 | 確認是用 `~/mp-venv/Scripts/python`（`py -3.12` 建的） |
| 鏡頭打不開 | 被其他程式占用、隱私權未允許 | 關掉 Teams／LINE；Windows 設定開放相機給桌面應用程式 |
