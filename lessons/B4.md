## 1. 三種遙控，其實是同一件事

> 🔊 這一課要用三種方式開車：手把、鍵盤、手機 App。看起來是三套東西，但在 ROS 2 眼裡它們做的是同一件事，就是對一個叫 cmd 底線 vel 的話題，發布「往前多快、轉彎多快」的速度指令。
> 你可以把 cmd vel 想成車子的方向盤和油門。不管是誰握著方向盤，車上的 ESP32 只管聽這個話題、照著轉輪子。也因此有一條很重要的規則：同一時間只能有一個人握方向盤，兩個程式同時發速度，車子就會抖動、亂跑。

```text title="示意圖（不用執行）"
 手把 ──► joy_node ──/joy──► yahboom_joy ──┐
 鍵盤 ──► yahboom_keyboard ─────────────────┼──/cmd_vel──► /YB_Car_Node（ESP32）──► 四顆馬達
 手機 App ──► rosbridge（WebSocket）────────┘
```

| 方式 | 誰發 `/cmd_vel` | 預設最高速 |
| --- | --- | --- |
| 手把 | `yahboom_joy` 節點（套件 `yahboomcar_ctrl`） | 線速度約 0.33 m/s、角速度約 1.25 rad/s（原始碼：上限 1.0 × 檔位 1/3、5.0 × 檔位 1/4） |
| 鍵盤 | `yahboom_keyboard`（節點名 `yahboom_keyboard_ctrl`） | 起始 0.2 m/s、1.0 rad/s，可加速到上限 1.0 m/s、5.0 rad/s |
| App | App 透過 `rosbridge_server` 發布 | 依 App 設定 |

:::tip
練習場地要空曠，地上不要有電線。第一次用新的控制方式時，先把車架空試一下方向，再放到地上。
:::

## 2. 手把：開機就能玩

> 🔊 手把是最快上手的方式，因為出廠系統開機時已經自動幫你啟動了手把控制。打開車子電源，等三十秒，打開手把電源看到綠燈，按開始鍵聽到嗶一聲，就代表手把可以用了。
> 但還差一步：要先按一下右上方的 R1 鍵，車子才會接受手把的速度指令。R1 就像汽車的手煞車開關，按一下放開手煞車，再按一下又拉起來。左搖桿前後控制前進後退，右搖桿左右控制轉彎，右邊四個按鍵控制攝影機雲台。

**啟動**（官方影片 TDdD7tqdnZs、04.Quick start control/1）：

1. 手把接收器插在 Pi 5 的 USB 孔（B1 已接好）。
2. 打開車子電源，等約 30 秒。
3. 打開手把電源，手把亮綠燈＝與接收器配對成功。
4. 按 **START**，車子嗶一聲＝手把控制可用。
5. 按一次 **R1**，開始控制。

**按鍵功能**（05.Robot control/3 與原始碼 `yahboom_joy.py`）：

| 按鍵 | 功能 |
| --- | --- |
| 左搖桿 上／下 | 前進／後退（左右無效） |
| 右搖桿 左／右 | 左轉／右轉（前後無效） |
| R1 | 速度控制開關：按一下允許手把控速，再按一下取消；也是雷達避障等「玩法」的暫停／繼續鍵 |
| START | 蜂鳴器開／關 |
| Y／A | 上方舵機 S2 向上／向下（範圍 −90～20 度） |
| X／B | 下方舵機 S1 向左／向右（範圍 −90～90 度） |
| MODE | 切換模式，**不要按**；切換後鍵值不對，程式會報錯退出 |

:::info
搖桿推一點點（小於 0.2）會被當成 0，這是原始碼裡的「死區」，避免搖桿沒回正時車子慢慢飄。舵機每收到一次按鍵訊息轉 1 度，按住不放就持續轉。
:::

## 3. 關掉開機自啟的手把（暫時與永久）

> 🔊 當你要改用鍵盤、App，或之後自己寫程式控制車子時，最好先把自動啟動的手把關掉，避免兩個人搶方向盤。
> 關法有兩種。暫時關：在容器裡用 ps 加大寫 A 列出所有程式，找到手把的兩個程式編號，用 kill 負九把它們結束，重開機後又會回來。永久關：在樹莓派主機上編輯 ros2 底線 humble 點 sh，把最後面的 root 斜線一點 sh 刪掉，以後開機和每次進容器都不會再啟動手把。

### 3.1 暫時關閉（重開機就恢復）

在**容器內**（開機自動開的 Docker 終端機，或你用 `sh ros2_humble.sh` 進的那個）：

```bash title="在車上 Docker 容器內"
ls /dev/input*
ps -A
```

- `ls /dev/input*` 看到 `js0` 之類的裝置＝手把接收器有掛進容器。
- `ps -A` 列出所有行程，找手把控制節點與 `joy_node` 兩個行程的 PID（官方範例是 171、173，**每次不同**）。

```bash title="在車上 Docker 容器內"
kill -9 171
kill -9 173
```

再 `ps -A` 確認手把行程消失（官方影片 hq0Zbi7BmFA 第 3 分 12 秒起示範）。

:::warn
每次執行 `sh ros2_humble.sh` 都會重新跑 `/root/1.sh`，也就是**每開一個新容器，手把控制就又啟動一次**。所以暫時關閉要在「你正在用的那個容器」裡做。
:::

### 3.2 永久關閉

在 **Pi 5 主機**（不是容器內）編輯腳本：

```bash title="在 Pi 5 主機"
vi /home/pi/ros2_humble.sh
```

vi 操作（官方影片示範）：

1. 按 `i` 進入編輯模式（官方影片說按 E，若出現交換檔警告時按 E 是「仍要編輯」）。
2. 把最後一行結尾的 `/root/1.sh` 刪掉，變成 `... yahboomtechnology/ros-humble:4.0.3 /bin/bash`。
3. 按 `Esc`，輸入 `:wq`，按 Enter 存檔離開。

想恢復時把 `/root/1.sh` 加回去即可。永久關閉後，重開機手把就不能用了，要用時改成手動啟動：

```bash title="在車上 Docker 容器內"
ros2 launch yahboomcar_ctrl yahboom_joy_launch.py
```

:::warn
上面這行是官方文件 05.Robot control/3 的寫法，但官方原始碼包裡的 launch 檔名是 `yahboomcar_joy_launch.py`（多了 car）。如果出現找不到檔案，改用 `ros2 launch yahboomcar_ctrl yahboomcar_joy_launch.py`，或用 `ls /root/yahboomcar_ws/src/yahboomcar_ctrl/launch/` 看車上實際的檔名（需實車確認）。也可以不用 launch，直接開兩個終端機分別執行 `ros2 run joy joy_node` 與 `ros2 run yahboomcar_ctrl yahboom_joy`。
:::

:::info
官方 04-1 還教了一個進階情境：如果你把控制板的 `ROS_DOMAIN_ID` 改成不是 20，自啟手把要跟著改容器內的 `~/.bashrc` 與 `/usr/lib/systemd/system/supervisor.service`，再用 `docker commit` 存成新映像、修改 `ros2_humble.sh` 改用新映像。文件裡的映像名 `192.168.2.51:5000/ros-humble:10.8` 是原廠內部範例，請換成你自己的名字。初學階段**不要改 ID**，就不需要做這些。
:::

## 4. 鍵盤：用 yahboom_keyboard 開車

> 🔊 鍵盤控制要自己動手啟動，正好複習上一課的流程：先關掉自動開的兩個終端機，再手動啟動 agent，進容器，看到車的節點之後，執行鍵盤控制程式。
> 鍵盤上的 i 是前進，逗號是後退，j 和 l 是原地左轉右轉。有一個新手一定會遇到的狀況：按了鍵車子沒反應。原因是鍵盤程式只收得到「目前被選中的那個終端機視窗」的按鍵，所以要先用滑鼠點一下執行鍵盤程式的終端機，再按鍵。

**步驟**（官方影片 G7wb07OQIIQ、hRfJiAchX_Y；05.Robot control/2）：

1. VNC 桌面：agent 終端機 Ctrl+C、Docker 終端機 `exit`（B3 第 3 節）。
2. 新終端機啟動 agent，必要時按 Reset 等連上：

```bash title="在 Pi 5 主機"
sh ~/start_agent_rpi5.sh
```

1. 另一個新終端機進容器：

```bash title="在 Pi 5 主機"
sh ros2_humble.sh
```

1. 容器內先確認節點，**暫時關掉手把**（第 3.1 節），再啟動鍵盤控制：

```bash title="在車上 Docker 容器內"
ros2 node list
ros2 run yahboomcar_ctrl yahboom_keyboard
```

1. 用滑鼠點一下這個終端機，然後按鍵。

**方向鍵**（大小寫皆可，`,` 與 `.` 只有小寫）：

```text title="鍵盤配置示意（不用執行）"
   u    i    o
   j    k    l
   m    ,    .
```

| 鍵 | 動作 | 鍵 | 動作 |
| --- | --- | --- | --- |
| `i` | 前進 | `u` | 前進＋左轉 |
| `,` | 後退 | `o` | 前進＋右轉 |
| `j` | 原地左轉 | `m` | 後退＋右轉 |
| `l` | 原地右轉 | `.` | 後退＋左轉 |

**速度鍵**：

| 鍵 | 作用 |
| --- | --- |
| `q`／`z` | 線速度與角速度同時 +10%／−10% |
| `w`／`x` | 只調線速度 +10%／−10% |
| `e`／`c` | 只調角速度 +10%／−10% |
| 空白鍵 | 立刻停 |
| `s` | 停止／恢復鍵盤控制（切換） |
| `t` | 切換 X／Y 軸，**本車普通輪胎不能側移，不要按** |
| Ctrl+C | 離開程式（離開前會自動送一次停車） |

:::info
放開按鍵後車子會自己停：原始碼每 0.1 秒讀一次鍵盤，連續 5 次沒收到方向鍵就把速度歸零。所以要「持續前進」就按住 `i`。畫面上會顯示目前速度，例如 `currently: speed 0.2 turn 1.0`；超過上限會印 `Linear speed limit reached!`。
:::

:::tip
離開鍵盤程式後，如果終端機打字怪怪的（不換行、看不到字），輸入 `reset` 再按 Enter 就會恢復，這是程式把終端機切成 raw 模式留下的後遺症（經驗建議）。
:::

## 5. 手機 App：ROS Robot

> 🔊 第三種方式是手機 App。亞博的 App 叫做 ROS Robot，安卓和蘋果的商店都搜得到。
> App 不是直接連 ESP32，而是透過樹莓派上一個叫 rosbridge 的程式，把手機的觸控轉成 ROS 話題。官方把它和手機建圖放在同一課，所以要開三個終端機：底層、App 用的建圖程式、攝影機，三個都要用 docker exec 進同一個容器。

**事前準備**：

- 手機安裝 **ROS Robot** App。
- 手機連到和車同一個網路：熱點模式就連 `Micro_ros`（密碼 `12345678`）。

**步驟**（官方 04.Quick start control/4、影片 P1vqjdfPqv8）：

1. 照第 4 節的 1～3 步：關自動終端機 → `sh ~/start_agent_rpi5.sh`（按 Reset 等連上）→ `sh ros2_humble.sh`。
2. 第一個容器終端機啟動底層資料處理：

```bash title="在車上 Docker 容器內"
ros2 node list
ros2 launch yahboomcar_bringup yahboomcar_bringup_launch.py
```

1. 開新的 Pi 5 終端機，查容器 ID 並進入**同一個容器**：

```bash title="在 Pi 5 主機"
docker ps -a
docker exec -it ef0e1b7da319 /bin/bash
```

1. 在第二個容器終端機啟動 App 建圖程式（裡面包含 rosbridge）：

```bash title="在車上 Docker 容器內"
ros2 launch yahboomcar_nav map_gmapping_app_launch.xml
```

1. 再開一個 Pi 5 終端機、同樣 `docker exec` 進同一容器，啟動攝影機：

```bash title="在車上 Docker 容器內"
ros2 launch usb_cam camera.launch.py
```

1. 打開手機 App：輸入**車的 IP**（熱點模式為 `10.42.0.1`，需實車確認 App 欄位格式）；`[zh]` 中文、`[en]` 英文；選 **ROS2**；影像話題選 **`/usb_cam/image_raw/compressed`**；按 **Connect**。
2. 用畫面上的**滑動輪盤**慢慢開車。這時 App 也會同步畫出光達建的地圖（A1 單元再細講）。

`map_gmapping_app_launch.xml` 的內容（原始碼包）：

```xml title="在車上 Docker 容器內"
<launch>
    <include file="$(find-pkg-share rosbridge_server)/launch/rosbridge_websocket_launch.xml"/>
    <node name="laserscan_to_point_publisher" pkg="laserscan_to_point_publisher" exec="laserscan_to_point_publisher"/>
    <include file="$(find-pkg-share yahboomcar_nav)/launch/map_gmapping_launch.py"/>
    <include file="$(find-pkg-share robot_pose_publisher_ros2)/launch/robot_pose_publisher_launch.py"/>
    <include file="$(find-pkg-share yahboom_app_save_map)/yahboom_app_save_map.launch.py"/>
</launch>
```

第一行就是 `rosbridge_websocket`：App 用 WebSocket（rosbridge 預設埠 9090）跟它溝通。

:::tip
這一課只要能用 App 開車就算過關。按「儲存地圖」會把地圖存到容器內的 `/root/yahboomcar_ws/src/yahboomcar_nav/maps`；因為容器有 `--rm`，離開前要先備份（A1 單元會教）。
:::

## 6. 出問題時怎麼辦

> 🔊 遙控出問題時，先問自己兩個問題：第一，速度指令有沒有發出來？第二，是不是有兩個程式在搶方向盤？
> 第一個問題可以在容器裡用 ros2 topic echo 斜線 cmd 底線 vel 直接看，有數字跑出來就是有發。第二個問題用 ros2 node list 看看，如果鍵盤和手把的節點同時存在，就先把其中一個關掉。這兩招在下一課會正式學到。

| 症狀 | 可能原因 | 解法 |
| --- | --- | --- |
| 按 START 沒有嗶聲 | agent 沒連上、手把行程被關掉、韌體不對 | 按擴展板 Reset 等約 30 秒；VNC 看 agent 終端機有無大量輸出；確認沒有把 `/root/1.sh` 刪掉 |
| 有嗶聲但推搖桿不動 | 沒按 R1 | 按一次 R1；若之前按過一次，再按反而會關掉 |
| 手把沒亮綠燈 | 手把沒電或沒配對 | 換 7 號電池；確認接收器插在 Pi 5 |
| 手把突然失控、按鍵對不上 | 不小心按到 MODE | 按回原模式（指示燈恢復），或重新啟動手把節點 |
| 鍵盤按了沒反應 | 終端機沒有被選中 | 滑鼠點一下執行 `yahboom_keyboard` 的終端機 |
| 鍵盤控制時車子抖動、忽動忽停 | 手把節點也在發 `/cmd_vel` | 容器內 `ps -A` ＋ `kill -9` 關手把（第 3.1 節） |
| `Package 'yahboomcar_ctrl' not found` | 不在容器內 | 先 `sh ros2_humble.sh` |
| 手動啟動手把 launch 找不到檔案 | 文件與原始碼檔名不同 | 改用 `yahboomcar_joy_launch.py`（第 3.2 節） |
| App 連不上 | 手機不在同一網路；rosbridge 沒啟動；IP 打錯 | 手機連 `Micro_ros`；確認第二個終端機的 `map_gmapping_app_launch.xml` 沒有報錯；IP 用 `10.42.0.1` |
| App 連上但沒有影像 | 攝影機沒啟動或話題選錯 | 第三個終端機啟動 `usb_cam`；話題選 `/usb_cam/image_raw/compressed` |
| 三個終端機互相看不到 | 用 `sh ros2_humble.sh` 開了多個容器 | 第二、三個終端機改用 `docker exec -it <ID> /bin/bash` |
| 車子往前走時偏一邊 | 正常的里程誤差或輪子打滑 | B6 會做線速度與角速度校準 |
