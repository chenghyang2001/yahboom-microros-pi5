## 規則

1. 開頭的 `---` front matter 欄位都要有；`needs_car` 填「是／否／部分」；`videos` 是官方 YouTube 影片 ID（逗號分隔，可空）。
2. 每單元 4～8 個 `## 數字. 小節`，**每個小節第一個內容一定是旁白**（`> 🔊`）。
3. 最後一個小節固定是 `## 小測驗`，3～5 題，`answer` 從 0 開始算。
4. 程式碼區塊用 ```` ```bash title="在哪台機器執行" ```` 標明執行位置：「在電腦 WSL（Jazzy）」「在 Pi 5 主機」「在車上 Docker 容器內」「在 Windows」。
5. 指令、套件名、話題名、檔名必須和研究筆記與原始碼**逐字一致**；不確定的寫「（需實車確認）」。
6. 官方文件有錯的地方（筆記裡標出的筆誤、ROS 1 殘留、foxy 路徑等）要用 `:::warn` 提醒。
7. 語氣：對完全沒碰過 ROS 的人說話，先講「為什麼」再講「怎麼做」，一個觀念一個比喻。
8. 全部繁體中文；英文專有名詞第一次出現時附中文解釋。
