Linux、SSH 與 Docker 速成

⏱ 1 小時🚗 真車：否
🎯 學習目標
學會操作這台車必備的 Linux 指令、用 SSH 遠端登入，並看懂車上 start_agent_rpi5.sh 與 ros2_humble.sh 兩支腳本在做什麼
✅ 完成標準
能 SSH 進一台 Linux，用 docker ps 找到容器 ID，再用 docker exec -it 開第二個終端進同一個容器

1. 為什麼要學這三樣

🔊 旁白文字

這台車的大腦是一台跑 Linux 的樹莓派，平常沒有接螢幕和鍵盤，你要從電腦遠端操作它。遠端操作的方式有兩種：一種是 VNC，看得到整個桌面；另一種是 SSH，只有一個文字終端機，但又快又穩。連進去之後，車上的 ROS 2 程式都放在 Docker 容器裡，所以你還要會開容器、進容器。這三樣東西，Linux 指令、SSH、Docker，就是你每次開工都會用到的基本功。今天花一小時把它練熟，之後在車上就不會手忙腳亂。

本單元可以全部在電腦上練：

要練的 在哪練
Linux 指令 電腦 WSL（Ubuntu 24.04）
SSH Windows 內建 ssh 指令；車到了再實際連
Docker WSL 裡有 Docker 的話可練 ros:humble 容器；沒有就先看懂，B3 單元在車上做

2. Linux 終端機十個必學指令

🔊 旁白文字

Linux 的終端機就像跟電腦對話的對講機，你打一行字，它回一段結果。先記住你永遠站在某個資料夾裡，pwd 告訴你在哪，ls 看這裡有什麼，cd 走到別的資料夾。波浪號代表你的家目錄。打字打一半按 Tab 鍵會自動補完，這能幫你少打很多錯字。還有一個救命鍵：Ctrl C，用來中斷正在跑的程式。在 ROS 裡，停止一個節點就是按 Ctrl C。

在電腦 WSL（Jazzy）
pwd                     # 我現在在哪個資料夾
ls                      # 這裡有哪些檔案（ls -a 連隱藏檔一起看）
cd ~                    # 回家目錄；cd .. 往上一層；cd /opt/ros 到指定路徑
mkdir -p test/src       # 建資料夾（-p 連上層一起建）
cat ~/.bashrc           # 印出檔案內容
nano test.txt           # 最適合新手的編輯器：Ctrl+O 存檔、Ctrl+X 離開
sudo apt update         # sudo = 用管理員權限執行；apt = 安裝軟體
hostname -I             # 看這台機器的 IP
ls /dev/ttyUSB*         # 看 USB 序列裝置（在車上會看到 /dev/ttyUSB0）
history                 # 看剛剛打過哪些指令
按鍵 用途
Tab 自動補完指令與檔名（按兩下列出所有可能）
↑ / ↓ 叫出上一個／下一個指令
Ctrl+C 中斷目前執行中的程式（停 ROS 節點就靠它）
Ctrl+Shift+C / Ctrl+Shift+V 在終端機裡複製／貼上

檔案系統重點：所有東西都在根目錄 / 底下。/home/pi 是車上 pi 帳號的家目錄（~），/dev 是裝置，/opt/ros/humble 是 ROS 2 安裝位置，/root/yahboomcar_ws 是容器內的車子工作空間。

💡 小提示

Linux 指令分大小寫，而且空格很重要。官方文件有幾處排版錯誤，例如 sshpi@...（應為 ssh pi@...）、Newgrp Docker（應為 newgrp docker），照抄會失敗。

3. SSH：遠端登入車子

🔊 旁白文字

SSH 讓你在電腦上打開一個終端機，但裡面打的每一行指令，都在遠方的樹莓派上執行，像是一條通往車子的電話線。格式是 ssh、帳號、小老鼠、IP。這台車連熱點時的 IP 是十點四十二點零點一，帳號是 pi，密碼是 yahboom。第一次連線會問你要不要信任這台主機，輸入 yes。輸入密碼時畫面不會顯示任何字，這是正常的，打完按 Enter 就好。要離開就輸入 exit。

步驟（車到了之後做；現在先看懂）：

  1. 電腦 WiFi 連上車子的熱點 Micro_ros，密碼 12345678。
  2. 開 Windows 的 PowerShell 或 WSL 終端機：
在 Windows
ssh pi@10.42.0.1
# 第一次會問 Are you sure you want to continue connecting (yes/no)? → 輸入 yes
# 輸入密碼 yahboom（畫面不會顯示，正常）
  1. 提示符號變成 pi@... 就代表你已經在車上了：
在 Pi 5 主機
hostname -I          # 看車的 IP
ls ~                 # 應該看得到 start_agent_rpi5.sh、ros2_humble.sh、config_robot.py
exit                 # 離開 SSH，回到你的電腦

傳檔案：用 scp（或 Windows 圖形工具 WinSCP）。

在 Windows
scp test.txt pi@10.42.0.1:~/          # 電腦 → 車子家目錄
scp pi@10.42.0.1:~/test.txt .         # 車子 → 電腦目前資料夾
SSH VNC
看到什麼 只有文字終端機 整個 Pi 5 桌面
速度 快、省流量 較慢
什麼時候用 下指令、看 log 要看 RViz、相機畫面、rqt 等視窗
⚠️ 注意

官方 Linux 課的範例帳號是 jetson、IP 是 192.168.2.93，那是別的產品。本車帳號是 pi；連熱點時 IP 是 10.42.0.1，連家裡 WiFi 時 IP 會變，要用 hostname -I 或 ros2 topic echo /rpi5_ip 查。

4. Docker 三個名詞：映像、容器、倉庫

🔊 旁白文字

Docker 有三個名詞一定要分清楚。用遊戲來比喻：映像是遊戲光碟，內容固定、不能改；容器是你把光碟放進主機後正在玩的那一局，可以存檔、可以亂玩。同一張光碟可以同時開好幾局，彼此互不影響。倉庫則是遊戲商店，例如 Docker Hub，可以下載別人做好的光碟。車上的 ROS 2 環境是一張叫 ros humble 的光碟，每次執行 ros2 humble 腳本，就是開一局新的遊戲。

名詞 比喻 在這台車上
映像 Image 遊戲光碟，唯讀範本 yahboomtechnology/ros-humble:4.0.3、microros/micro-ros-agent:humble
容器 Container 正在玩的那一局，可寫入 執行 ros2_humble.sh 後產生的那個容器
倉庫 Registry 遊戲商店 Docker Hub

最重要的一個性質：容器裡改的東西，是寫在「這一局」上面。容器一刪掉，改的東西就不見了，除非你用 docker commit 把這一局存成一張新光碟。

5. Docker 常用指令實作

🔊 旁白文字

現在動手練。如果你的 WSL 裡有裝 Docker，可以下載官方的 ros humble 映像，開一個跟車上同版本的 ROS 2 容器。練習的重點有兩個：第一，用 docker ps 找到容器的名字或 ID；第二，用 docker exec 再開一個終端機，進入同一個容器。用 docker exec 進去的新終端機，不會自動載入 ROS 環境，要自己先 source 一次，這個小細節在車上也一樣。

先確認有沒有 Docker：

在電腦 WSL（Jazzy）
docker --version
# 出現 command not found 就代表沒裝，這一節先看懂即可（B3 在車上實作）

終端機 1：開一個 Humble 容器

在電腦 WSL（Jazzy）終端機 1
docker run -it --rm --name ros_practice ros:humble
# 第一次會下載映像，稍等。提示符號變成 root@xxxx:/# 就是進到容器了
在電腦 WSL（Jazzy）終端機 1（容器內）
ros2 topic pub /chatter std_msgs/msg/String "{data: 'hello from container'}"

終端機 2：進入「同一個」容器

在電腦 WSL（Jazzy）終端機 2
docker ps                                  # 看執行中的容器：CONTAINER ID、IMAGE、NAMES
docker images                              # 看本機有哪些映像
docker exec -it ros_practice /bin/bash     # 用名字或 ID 進入同一個容器
在電腦 WSL（Jazzy）終端機 2（容器內）
source /opt/ros/humble/setup.bash          # exec 進來的終端要自己 source
ros2 topic echo /chatter                   # 收得到終端機 1 發的訊息 → 成功

其他常用指令

指令 用途
docker ps -a 連已停止的容器一起列出
docker stop <ID或名字> 停止容器
docker commit <容器ID> 新名字:標籤 把容器目前的狀態存成新映像
docker cp <容器ID>:/路徑 ./ 從容器複製檔案到主機
exit 離開容器終端（若是第一個終端，容器會跟著停止）
💡 小提示

容器 ID 可以只打前幾碼，例如 docker exec -it c5 /bin/bash，只要能唯一辨識就行。車上的容器沒有取名字，每次 ID 都不同，所以一定要先 docker ps 查。

6. 逐行看懂 start_agent_rpi5.sh

🔊 旁白文字

現在來看車上真正的腳本。第一支是 start agent rpi5，它只做一件事：用 Docker 開一個 micro ROS agent 容器，也就是翻譯官。最後面的參數最重要：serial 代表走 USB 序列線，dev 後面是 ttyUSB0 這個裝置，b 九二一六零零是傳輸速度。被註解掉的那一行是 WiFi 版，給電腦或虛擬機用的。記住，翻譯官同一時間只能開一個，重複開會報錯。

原始碼完整內容（~/start_agent_rpi5.sh）：

在 Pi 5 主機（檔案內容）
#!/bin/bash
# WIFI
#docker run -it --rm -v /dev:/dev -v /dev/shm:/dev/shm --privileged --net=host microros/micro-ros-agent:humble udp4 --port 8090 -v4
# serial
docker run -it --rm -v /dev:/dev -v /dev/shm:/dev/shm --privileged --net=host microros/micro-ros-agent:humble serial --dev /dev/ttyUSB0 -b 921600 -v4
片段 意思
docker run -it 開一個新容器，並給你互動終端（-i 互動、-t 終端）
--rm 容器結束後自動刪除
-v /dev:/dev 把主機的裝置資料夾掛進容器，容器才看得到 /dev/ttyUSB0
-v /dev/shm:/dev/shm 共享記憶體，ROS 2 的 DDS 通訊會用到
--privileged 給容器存取硬體的權限
--net=host 容器直接用主機的網路，車上的話題才能被電腦看見
microros/micro-ros-agent:humble 映像名稱：官方 micro-ROS agent，Humble 版
serial --dev /dev/ttyUSB0 -b 921600 走序列埠、裝置 /dev/ttyUSB0、鮑率 921600
-v4 日誌詳細程度（數字越大印越多）；注意這個 -v4 是 agent 的參數，和前面掛載用的 -v 不同
⚠️ 注意

agent 只能開一個。出廠時開機就已自動啟動 agent，再手動開會報錯。正確結束方式是在 agent 終端按 Ctrl+C，不要直接關視窗（關視窗容器會留在背景）。殘留時：docker ps -a | grep microros/micro-ros-agent 找 ID，再 docker stop <ID>。

7. 逐行看懂 ros2_humble.sh

🔊 旁白文字

第二支腳本是 ros2 humble，它開的是裝滿車子程式的 ROS 2 容器。前面幾行是讓容器裡的視窗程式，例如 RViz，可以顯示在樹莓派的桌面上。接著把手把和相機兩個裝置掛進容器，最後用 yahboom 的 ros humble 映像，執行容器裡的一支啟動腳本。要記住兩件事。第一，它有 rm 選項，容器裡裝的東西關掉就沒了。第二，每執行一次就開一個全新容器，想多開終端要用 docker exec，不能再跑一次這支腳本。

原始碼完整內容（~/ros2_humble.sh）：

在 Pi 5 主機（檔案內容）
#!/bin/bash
xhost +
docker run -it --rm \
--privileged=true \
--net=host \
--env="DISPLAY" \
--env="QT_X11_NO_MITSHM=1" \
-v /tem/.X11-unix:/tmp/.X11-unix \
--security-opt apparmor:unconfined \
-v /dev/input:/dev/input \
-v /dev/video0:/dev/video0 \
yahboomtechnology/ros-humble:4.0.3 /bin/bash /root/1.sh
行 意思
xhost + 允許任何程式連到桌面顯示（讓容器內的 RViz 能開視窗）
docker run -it --rm 開新容器、給終端、結束就刪除
--privileged=true、--net=host 同 agent：硬體權限、共用主機網路
--env="DISPLAY"、QT_X11_NO_MITSHM=1 把顯示器位置傳進容器，修正 Qt 視窗顯示問題
-v ...X11-unix:/tmp/.X11-unix 掛載桌面顯示用的通道
--security-opt apparmor:unconfined 關掉 AppArmor 安全限制
-v /dev/input:/dev/input 掛載輸入裝置，手把接收器在這裡
-v /dev/video0:/dev/video0 掛載 USB 相機
yahboomtechnology/ros-humble:4.0.3 車子 ROS 2 容器的映像與版本
/bin/bash /root/1.sh 容器啟動後執行 /root/1.sh（出廠用它自動啟動手把控制；內容需實車 cat /root/1.sh 確認）
⚠️ 注意

原始碼小瑕疵：-v /tem/.X11-unix:/tmp/.X11-unix 的 /tem 應該是 /tmp（筆誤）。因為同時用了 --net=host，桌面視窗通常仍能顯示，所以出廠沒人發現；若遇到容器內 RViz 開不出視窗，可以先檢查這一行（需實車確認）。另外 xhost + 會關閉桌面的存取控制，只在可信任的區網使用。

⚠️ 注意

--rm 的後果：容器內做的修改（裝套件、改 ~/.bashrc 的 ROS_DOMAIN_ID、建好的地圖）關掉容器就消失。要保留就在主機另開終端 docker ps 查 ID，再 docker commit <ID> 新映像名:標籤，並把 ros2_humble.sh 最後的映像改成新的；地圖等檔案也可以用 docker cp 複製出來。

8. 車上的標準開工流程

🔊 旁白文字

把今天學的串起來，就是你每次在車上開工的流程。先在主機開翻譯官，再打開車子電源或按 reset，等 ESP32 連上。接著另開一個終端執行 ros2 humble 進容器，打 ros2 node list，看到 YB Car Node 就代表三層全通了。要開第二、第三個終端，在主機用 docker ps 查容器 ID，再用 docker exec 進去。這套流程請練到不用看講義也打得出來。

在 Pi 5 主機 終端機 1
sh ~/start_agent_rpi5.sh          # 開翻譯官；接著打開車子電源或按控制板 Reset，等約 10 秒
在 Pi 5 主機 終端機 2
sh ros2_humble.sh                 # 進 ROS 2 容器（官方有時寫 ./ros2_humble.sh，效果相同）
在車上 Docker 容器內
ros2 node list                    # 看到 /YB_Car_Node 就成功
在 Pi 5 主機 終端機 3
docker ps                         # 找 yahboomtechnology/ros-humble:4.0.3 那一列的 CONTAINER ID
docker exec -it <容器ID> /bin/bash # 進同一個容器開第二個終端
ℹ️ 補充

車上的容器 ~/.bashrc 已經設好 ROS 環境，docker exec 進去後通常可直接用 ros2；若出現 ros2: command not found，執行 source /opt/ros/humble/setup.bash（需實車確認）。另外出廠時開機就已經自動開好 agent 與容器兩個視窗，VNC 桌面上看得到；這時直接用那兩個視窗即可，不必重開。

常見錯誤 原因 解法
第二個終端看不到第一個終端開的節點 又跑了一次 ros2_humble.sh，開到新容器 改用 docker ps + docker exec
開 agent 報錯 背景已經有一個 agent Ctrl+C 原本那個，或 docker stop 殘留容器
ros2 node list 沒有 /YB_Car_Node agent 沒開、沒按 Reset、或 ROS_DOMAIN_ID 不是 20 依序檢查；ls /dev/ttyUSB* 確認序列線
在主機打 ros2 找不到指令 ROS 2 只裝在容器裡 先進容器再打
